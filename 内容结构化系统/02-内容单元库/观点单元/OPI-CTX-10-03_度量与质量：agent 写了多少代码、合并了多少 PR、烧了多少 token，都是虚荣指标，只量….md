## 核心内容

**核心判断（原文照抄）**：度量与质量：agent 写了多少代码、合并了多少 PR、烧了多少 token，都是虚荣指标，只量出产出、量不出价值。真正该看的是产品是否变好、bug 是否更少、用户是否真的喜欢。Linear 靠“零 bug 政策 + 一周 SLA”，让 coding agent 先做第一遍修复。
