## 核心内容

**核心判断（原文照抄）**：这篇内容的核心不是“更会 prompt 一个 coding agent”，而是把人的一次性提示升级成可复用、可触发、可记账、可复盘的 agent loop。Loop engineer 的工作，就是设计让 agent 自动被唤醒、读取上下文、执行任务、写入状态、积累信号，并在下一轮继续变好的外部系统。
