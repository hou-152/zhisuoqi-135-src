# 早上讨论：一页

## 这是什么

一张知识图：**194 个概念、353 条依赖**，从 12 篇 AI 内参文章里抽出来的。

两种视图（图谱 / 星球），可以转、可以点开任一个概念看它的来路。

**已经能跑**——双击 `prototype/知所栖-135-概念图.html` 就开，不装任何东西、不联网、不上传。

## 三个能看的地方

| 看什么 | 怎么看 |
|---|---|
| **图谱模式** | 横轴 12 个来源分列、纵轴依赖层级 L0–L15。一眼看出哪一列最厚、哪一层最密 |
| **星球模式** | 点右上角「星球」。看整体形状和颜色分布 |
| **点开一个点** | 右侧滑出：它依赖什么、它解锁什么，邻居可以一直点着走下去 |

实线 = 多次生成一致的骨架（87 条）；虚线 = 机器推测的候选（266 条）。**两种线的区别本身就是产品的一部分。**

## 一个提议

今天讨论，可以拿这句话当判据：

> 48 小时后只能交一份，评委按 **场景价值 40 / 创新 25 / 完成度 25 / 体验 10** 打分。
> 所以不比哪个想法好，比**哪个版本到 09-15 10:00 能跑通完整闭环、能当场演示**。

理由：四路并行 = 每路只拿到 25% 的时间，最后一定有人跑不通。**先定判据比先定方案省时间。**
