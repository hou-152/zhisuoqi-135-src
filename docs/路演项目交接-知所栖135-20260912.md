## 网页和本地 App 的关系

它们是同一产品的两种壳，但当前还存在两个需要修的漂移点：

1. 命令行网页使用 `scripts/serve-lib.mjs`；App 使用构建复制到 `app/lib/serve-lib.mjs` 的副本。两份文件当前不一致，App 副本缺少最新的 `/api/orchestrate` 分支。
2. `prototype/知所栖-壳.html` 已比 `app/assets/prototype/知所栖-壳.html` 新。App 资源中的主动层数据相同，但页面脚本落后；重建前不能把“App 与网页一致”当作事实。

同步顺序是：

```sh
node scripts/build-shell.mjs
node scripts/build-app.mjs --skip-pack
```

这只同步本地资源，不涉及发布。发布、删除、移动和公开推送仍按项目边界处理。

## 路演可以怎么讲

- 我们把 Skill 方法论编译成可操作的界面：阅读给分层解释，决策要求写出判据和代价，实验要求给出真实例子，复述不过会倒回先修概念。
- 概念图是导航和证据，不是“点一下就学过”的进度条；主动层只把经过筛选的 53 个节点交给路线。
- 我们能证明产品流程在本地、网页和 App 上跑通；暂时不能证明学习效果，也不能把 74 篇尚未读全文的材料说成已入库。
