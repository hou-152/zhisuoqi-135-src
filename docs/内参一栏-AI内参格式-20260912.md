# 内参一栏：把今天的文章按「AI 内参」格式接进壳（2026-09-12 深夜）

## 一句话

壳的左栏多了第六格「**内参**」：列今天的期次文章，点开是详情页 ——
**主题 · 重要等级 · 地址 → 配图 → 原文子链接 + 原文简介 + 入选理由 → 三级笔记 / 概念网络 / 费曼 ×3 / 阅读原文**。
格式照所有者给的《serious AI 内参》（`做中学·AI`）与飞书两份主题精选（Context Engineering / Harness Engineering）。

## 一、格式从哪来（每一项的出处）

| 项 | 出处 | 状态 |
|---|---|---|
| 主题 | 真 LLM 生成（6–12 字，说的是「这一篇讲的那个东西」，不是标题缩写） | 实测 |
| 重要等级 ★1–5 | 真 LLM 生成，判据＝通用性 / 不可替代性（有没有一手事实或机制）/ 时效性；判据原文在页面「入选理由」卡里可见 | 实测 |
| 地址 | `原文/<slug>.md` 头部的 `- 原文：` 字段 | 实测 |
| 配图 | 程序化 SVG（见第四节） | 实测 |
| 原文简介 | `原文/<slug>.md` 头部的 `- 摘要：`（Reader 快照自带） | 实测 |
| 入选理由 | 真 LLM 生成（2 句以内，说清今天为什么值得读） | 实测 |
| 三级笔记 | `三级笔记/<slug>.md`，markdown → HTML 渲染 | 实测 |
| 概念网络 | `概念辞典/<slug>.md` → 拆成概念卡（名称 + 原文 context 引文 + 费曼一下） | 实测 |
| 费曼 ×3 | ① 30 秒版＝`拆解五维/*.json` 的 `feynman.demo`；② 3 分钟版＝`AI费曼/<slug>.md`；③ 验收版＝`feynman.rubric` | 实测 |
| 阅读原文 | **只放子链接与元信息**（来源 / 作者 / 字数 / 抓取时间），不转载全文 | 按所有者口径 |

## 二、与参照格式的有意差异

- **没有「收藏」「公开笔记」**。所有者口径：还没有账号登录，这两项不做。
- **原文不进页面**。所有者口径：原文只保留一个子链接。
- **费曼 ×3 的三档是本项目自己的口径**，不是抄来的：短版讲给完全不懂的人，长版讲清机制，
  第三档是**验收版**——把「讲完要答得出的点」摆出来，答不出就回到前两版重讲。
  这跟项目主线的费曼验收层（`prototype/知所栖-135-基础框架.html` 的限速器）是同一个立场。
- 配图语言照 `anthropic-art` 的 `references/style-spec.md`：满幅不透明色块（八色之一）＋
  不规则象牙白承载形 `#FAF9F5` ＋ 近黑 `#141413` 圆头手势线。

## 三、数据流与命令

```sh
node scripts/build-neican.mjs      # → knowledge/内参-260912/内参-页面数据.json（203 KB，10 篇）
node scripts/build-shell.mjs       # 注入 payload.neican → prototype/知所栖-壳.html
node scripts/build-public.mjs      # → deploy/zhisuoqi-135/index.html（单文件，522 KB）
```

- **元数据缓存**：`knowledge/内参-260912/内参-元数据.json`。LLM 只补缺的篇目，
  重跑不重烧 token（这一轮首跑 10 次 / 20,820 tokens，补三次 max_tokens 截断后 3 次 / 6,288 tokens）。
- **篇目顺序与字数**直接读 `编辑日志.md`（那一轮的记账就是权威），不另建清单。
- LLM 走 `.private/llm.env`（600，gitignored），脚本只补未设置的变量，不打印任何值。

## 四、配图为什么是 SVG 而不是位图

`anthropic-art` skill 规定要用「built-in image generation tool」出位图。
**本次会话没有可用的位图生成工具**（工具表里没有 image_gen），所以改为按同一份 style-spec
程序化生成 SVG：确定性抖动（seed=slug）＋ 11 个手势线字形（抽屉柜 / 台阶 / 漏斗 / 分叉 / 回路 /
层叠 / 天平 / 网 / 梯 / 齿轮 / 波），配色从 style-spec 的八色里按语义选。

**这是降级，不是等价物**：线条的「手抖感」是算法抖动，不如真模型画得有呼吸。
要换成位图：拿到 image_gen 工具后，按 `anthropic-art` 的 prompt contract 重出 10 张，
替换 `内参-页面数据.json` 里每篇的 `hero` 字段即可，模板不用动。

**两处验收脚本本身被改过，理由写在这里**：

1. `check-public.mjs` 的「左栏 **5** 格」→「**6** 格」。产品有意加了一格，断言跟着改。
2. `check-public.mjs` 的 Chrome 参数加了 `--no-proxy-server`。
   本机开着系统代理时，假域名 `zhisuoqi-135.test` 被代理拦成 **502**，页面根本没加载，
   21 条断言全部假失败（报 `DATA is not defined`）。加了这个参数才是真在测产品。
