## 1. 这个视图要回答什么

一句话：**AI 时代要学的每一件事，以及它们之间的先后。**

对应 Marble 的 `Everything a child learns.`。差别只有一处，也是全部价值所在：

| | Marble | 本视图 |
|---|---|---|
| 点的含义 | 所有人该学的（课程标准） | 待学 / 已学的概念 |
| 线的含义 | 课程标准里的先修关系 | 依赖关系（认知前提） |
| 颜色 | 学科 | 来源文章（12 篇） |
| **位置** | 高度 = 年龄 4–15 | **高度 = 依赖深度 L0–L8** |
| 数据集 | 1,590 点 / 3,221 边 | **194 点 / 171 边（投票后）** |

**Marble 是死的（课程标准发完就不动），本视图是活的（学一个，颜色变一个）。**

## 2. 两个轴：实测结论

### 纵轴 = 依赖深度（L0–L8）

不是拍脑袋定的，是测出来的：

| 候选口径 | 实测分布 | 结论 |
|---|---|---|
| 抽象层级（操作→方法→判据→模型→世界观） | 1%, 12%, 33%, **45%**, 9% | ❌ 45% 挤在「心智模型」一层，分不开 |
| 理解门槛（读懂它要多少准备） | 1%, 26%, **43%**, 27%, 4% | ✅ 分布可用 |
| **依赖深度（图的自然属性）** | L0:30 L1:58 L2:37 L3:33 L4:20 L5:9 L6:4 L7:2 L8:1 | ✅ **最终采用** |

**抽象层级失败的根因**：内参文章几乎全是观点，概念在「概念视角」下是同一类东西。**读者视角（门槛）分得开，概念视角（层级）分不开。**

**最终用依赖深度**，因为它是图自身的属性，不引入第二个主观判断。

### 横轴 = 力导向布局，不加人工分类

**依据**：补边前后统计，**86–95% 的依赖边发生在同一篇文章内部**（Marble 是 94% 在同一学科内部，结构同构）。

**含义**：簇边界是依赖关系自己聚出来的，不需要事先分类。「共享来源」比「显式互链」更能反映真实结构 —— 这与 llm_wiki 把「来源重叠」权重设为最高（×4.0，高于直接链接 ×3.0）是同一个判断。

**现状**（以投票后 171 条边为准）：

| | 基线 87 条（5 次投票≥3/5） | 补边后 171 条（4 次投票≥2/4） | 单次补边（**不可复现，仅作对照**） |
|---|---:|---:|---:|
| 覆盖概念 | 111 / 194（57%） | **181 / 194（93%）** | 194 / 194 |
| 弱连通分量 | 28 | **21** | 12 |
| 最大分量 | 12 | **33** | 99 |
| 深度 | 5 层 | 6 层 | 9 层 |

**图是碎的，这是真实状态。** 21 个分量、最大 33 个点——**离 Marble 的单一连通图差得远**。原因是依赖密度只有它的一半（见 4.2），而可复现的边更少。

### 颜色 = 来源文章

12 篇内参文章 → 12 色。可点击筛选。

**注意**：颜色是**来源**，不是**主题**。同一篇文章的概念会分布在不同高度层，所以颜色在视觉上是混合的 —— 这是正确的，Marble 也一样（同学科的点分布在不同年龄）。


## 4. 必须记住的三条边界

### 4.1 单次生成不可复现，必须投票

同一个 prompt、温度 0：

| 阶段 | 各次跑出的边数 | 投票后采纳 |
|---|---|---|
| 基线（文章内部结构边） | 112 / 145 / **27** / 126 / 125 | ≥3/5 → **87 条** |
| 补跨簇边 | 112 / 119 / **72** / 74 | ≥3/4 → 仅 **27 条**；≥2/4 → 84 条 |

**补边四次共产生 288 条不同的候选边，其中 204 条（71%）只出现一次。**

**单次结果不能进产品。** 这条对基线成立，对补边**尤其**成立——补边的单次结果看起来最漂亮（孤立点 83→0、碎片 28→12、9 层深度），但那是**不可复现的过拟合**。四次投票后同样指标退化为：碎片 21、最大分量 33、深度 6 层。

**由此得到一条产品结论**：**结构性边**（框架 → 它的组成部分，如「学习三阶段 → 好奇探索」）多次跑高度一致，可自动生成；**跨主题的「意外连接」不稳定**，每次跑出来的是一批不同的灵感。前者可作骨架，后者只能作**待筛候选**——这恰好印证了 llm_wiki 把这类动作收窄成「建页 / 深挖 / 跳过」三选一的判断：**机器负责发现，判断必须留给人。**

### 4.2 这批概念的依赖密度只有 Marble 的一半

| | Marble | 本视图（补边后） |
|---|---:|---:|
| 边/点 | 2.03 | 1.03 |
| 深度 | 28 层 | 9 层 |
| 人工标定 | 课程标准（有外部依据） | LLM 生成（**无外部依据**） |

**根因**：Marble 的先修关系是课程设计者写死的；本视图的边是 LLM 从文章里推断的，而这批概念大多是**并列的洞察**而非**递进的技能**。

**表达纪律**：路演时不能说「我们复刻了 Marble」。能说的是：**形式同构，密度受限于语料类型。**

### 4.3 实证状态

- 0 环、0 空话理由（每次跑都是）
- 人工抽检：单次 12 条，约 88–100% 合理
- **未做**：用户研究、学习效果验证、跨语料泛化验证

## 5. 两种视图模式

形式参考 candobear infra「知识体系」（Marble V1 的中文化版，3598 主题 / 4593 依赖，含课标对齐），**只借形式，不借数据**。

| | **图谱**（默认） | **星球** |
|---|---|---|
| 布局 | 纵轴 = 依赖层级 L0–L15；横轴 = 12 个来源分列 | 球面均布（Fibonacci sphere） |
| 视觉 | 每列一条淡色带 + 列顶标签；横向层级参考线 + 右侧 L0–L15 标注 | 均匀球面，连线穿过球体 |
| 拖拽 | 平移 | 旋转 |
| 用来看 | **结构和层级**——谁在什么深度、哪一列最厚 | **整体形状**——194 个点的密度与色彩分布 |

URL 加 `#sphere` / `#grid` 直接进对应模式。

**为什么星球不跑力导向**：先试了「球面初始化 + 边引力 + 每步拉回球面」，结果球被拉成一团歪的。candobear 那个球是**纯几何分布**——它的用途是看整体，不是看结构。**结构和整体拆成两个视图，各司其职。**

## 7. 还没接上的部分

1. **颜色 = 学习状态**（图上现在按来源着色）。要接三色：没学过 / 学过 / **漏点没补**。两色看不出「虚高」——费曼漏了但没补的概念会看起来和学会了一样。
2. **成就系统**：位置固定（依赖深度不动），颜色随学习记录变。**位置绝不能动**，否则用户的空间记忆作废。
3. **本地存储**：原型现在无状态（刷新即回到初始布局）。学习记录应落 localStorage，与 `prototype/知所栖-135-基础框架.html` 的 `zss135.checkpoint.v1` 保持同一套 key 规范。
4. **LLM key**：原型不调 LLM，无 key 泄露风险。若后续接入，必须走 `serve-135.mjs` 代理，**不得把 key 写进 HTML**。
