# 知所栖 135 · 路径视图 PLAN

日期：2026-09-13
状态：交给 DeepSeek 执行前的产品与交互计划
范围：只处理「前置内容／学习路径选择」；暂不处理费曼验收、课程内容生产、公开发布。

## 1. 要解决的问题

知所栖当前有 936 个概念、依赖关系和 LLM wiki，能回答「哪些概念有关」，但网页用户仍不知道：

- 为了一个目标，先学哪个；
- 这个概念为什么现在出现；
- 哪些前置必须学，哪些可以跳过；
- 卡住后应该回到哪里；
- 如何从知识图谱进入一条有限路径。

产品目标不是把 936 个概念排成一条总课程，而是在现有网站中增加一种「路径视图」：

> 知识图谱负责展示知识怎么连；路径视图负责告诉用户现在怎么走。

## 2. 当前产品基础

现有网站已经有：

- 左栏：内参、知识体系、搜索、21 个主题；
- 主区：图谱、关系、星球；
- 概念卡：定义、来源、前置、解锁、关系、层级、深看；
- 概念地图：936 个概念、依赖边、关系边、主题簇；
- 依赖边已区分 `hard` 与 `soft`，并带理由和审核字段。

这些结构保留。路径是同一知识体系上的新观察方式，不另做一套课程系统。

## 3. 方案选择

已讨论四种形态：

- A「路径优先」：进入网站先选问题，再进入路线；最清楚，但会削弱现有知识图谱入口。
- B「导师编排」：图谱旁边出现导师建议栏，告诉用户现在学什么、为什么；最符合知所栖的产品主张。
- C「路径地图」：在图谱上高亮当前主路径和少量分支；最容易展示路径本身。
- D「课程章节」：按章节连续学习；开发最稳，但容易变成普通课程平台。

本计划采用 **B + C**：

- B 负责产品逻辑：导师告诉用户当前该学什么、为什么；
- C 负责视觉表达：主区在现有图谱上高亮主路径，其他节点降噪。

## 4. 目标视图结构

### 4.1 顶部模式

现有主区：

```text
图谱｜关系｜星球
```

改为：

```text
路径｜图谱｜关系｜星球
```

「路径」放第一位，作为默认学习观察方式；其他三个视图继续保留。

### 4.2 左栏

保留现有主题列表。用户点击主题后，主题顶部增加路径入口：

```text
循环与自主执行

推荐路径：
- 理解 AI 如何持续行动 · 6 个概念
- 理解 Agent 如何恢复长任务 · 5 个概念
- 理解多 Agent 如何协作 · 7 个概念
```

主题仍然是知识入口，路径是主题中的编排入口。

### 4.3 主区路径视图

进入一条路径后，显示：

```text
路径：理解 AI 如何持续行动

① AI Agent
  ↓
② Tool
  ↓
③ Agent Loop
  ↓
④ State Management
  ↓
⑤ Agent Harness
```

主区同时保留图谱背景，但只高亮：

- 当前节点；
- 已完成节点；
- 下一步节点；
- 当前节点的强前置；
- 当前允许的少量分支。

其他概念变灰，可继续点击探索，但不进入当前主路径。

### 4.4 右侧概念卡

复用现有概念卡，在顶部增加路径上下文：

```text
当前路径第 3 步 / 共 6 步

当前概念：Agent Loop

为什么现在学：
不理解循环，就无法理解 Agent 如何持续行动。

前置：Tool ✓
下一步：State Management
卡住时回退：Tool

[学习这个] [查看前置理由]
```

费曼功能不属于本计划验收条件；已有解释、来源、关系和深看内容可继续保留。

### 4.5 分支

只有目标不同才出现分支。例如学完 Agent Loop 后：

```text
接下来你更关心什么？

- 任务为什么能持续推进 → State Management
- AI 怎样安全调用外部能力 → Permission Boundary
- 想继续了解底层机制 → Memory
```

每个分支必须有理由；不因图谱中存在多条关系就全部展示。

### 4.6 回退

卡住时只显示一个最小回退点：

```text
你现在卡在 Agent Harness。
建议先回到：Agent Loop。
原因：Harness 是组织 Agent Loop、状态、权限和错误处理的运行系统。
```

不把全部祖先节点铺成清单。

## 5. 路径规则

### 5.1 关系分类

| 类型 | 判断 | 页面行为 |
|---|---|---|
| `hard` 强前置 | 不懂就无法完成当前目标，或会严重误解后续概念 | 默认进入主路径 |
| `soft` 弱前置 | 懂了更顺，但不懂也能继续 | 推荐，可跳过 |
| `support` 支撑材料 | 提供案例、证据或术语，不改变顺序 | 折叠展示 |
| `related` 旁支关系 | 有关但不是当前目标必需 | 放入相关概念，不进主路径 |

### 5.2 主路径排序

默认按以下方向排序：

```text
低抽象 → 高抽象
对象 → 机制
单点 → 组合
解释 → 判断
```

先根据目标反向收集 `hard` 前置，再由人工确认主路径顺序；`soft` 不自动加入主路径。

### 5.3 展示预算

默认页面只展示：

- 当前步骤：1 个；
- 下一步主推荐：1 个；
- 可选分支：最多 2 个；
- 相关概念：折叠；
- 更深前置：只显示数量和入口。

路径初始长度建议为 5—7 个主步骤。这个数字是产品预算，不是已验证的学习科学结论。

### 5.4 跳过与回退

允许跳过的情况：

- 用户已有该概念的可靠证据；
- 当前目标不使用该能力；
- 用户选择直接进入应用案例。

回退规则：

- 强前置缺失：回到最近的 `hard` 前置；
- 弱前置不足：提供补充，不强制回退；
- 当前概念与目标不匹配：切换目标分支，不回到全图。

## 6. 一条真实路径样例

目标：为什么 AI 能连续做事，而不只回答一次？

主路径：

```text
AI Agent → Tool → Agent Loop → State Management → Agent Harness → Verification Loop
```

可选分支：

```text
Agent Loop → Permission Boundary
Agent Loop → Memory
Agent Loop → Agent Lifecycle
```

这条路径只是一条可展示的真实样例，不代表已经冻结全部主题路线。

## 8. 暂不做

- 不把 936 个概念排成一条总课程；
- 不让 LLM 每次从全图自由重排路线；
- 不把所有关系边都变成页面选择；
- 不把 `related-to` 自动升级为前置；
- 不用中心性、热度或关系数量直接决定教学顺序；
- 不做跨主题的全局学习百分比；
- 不处理费曼验收；
- 不发布公网；
- 不修改概念地图的源数据。

## 9. 完成标准

一条路径视图达到以下条件即可验收：

1. 用户能从一个问题或主题进入路径；
2. 页面显示 5—7 个以内的有限主路径；
3. 当前节点在图谱中明显高亮；
4. 每个步骤都能看到“为什么现在学它”；
5. `hard`、`soft`、相关概念有明显区别；
6. 每次最多出现 1 个主推荐和 2 个分支；
7. 用户卡住时能回到一个明确的最小前置；
8. 可以从路径返回图谱、关系和星球视图。
