## 二、任务一句话

把“路径”嵌入现有知识体系网站：用户从主题或问题进入一条有限的策展路径，主区高亮路径，右侧概念卡说明“为什么现在学它、前置是什么、下一步去哪”；图谱、关系、星球继续保留。

## 三、现有网站不可破坏的基础

```text

主区：图谱／关系／星球
概念卡：定义／来源／前置／解锁／关系／层级／深看
```

必须保持：

## 四、要做的页面行为

### 1. 新增路径模式

主区顶部由：

```text
图谱｜关系｜星球
```

变为：

```text
路径｜图谱｜关系｜星球
```

路径是默认学习观察方式；其他三个模式保留。

### 2. 主题进入路径

点击左栏主题后，主题区域显示少量路径入口。例如：

```text
循环与自主执行

- 理解 AI 如何持续行动
- 理解 Agent 如何恢复长任务
- 理解多 Agent 如何协作
```

第一版可以只提供一条真实路径：

```text
AI Agent → Tool → Agent Loop → State Management → Agent Harness → Verification Loop
```

不要为 21 个主题批量编造路线。

### 3. 主区高亮路径

路径模式中：

- 显示当前路线标题和目标；
- 显示 5—7 个以内的主步骤；
- 当前节点高亮；
- 已完成节点有状态；
- 下一步主推荐突出；
- 最多显示 2 个可选分支；
- 其他概念降噪，但仍可通过图谱探索。

### 4. 概念卡增加路径上下文

在现有概念卡顶部增加：

```text
当前路径第 3 步 / 共 6 步
为什么现在学：……
前置：Tool ✓
下一步：State Management
卡住时回退：Tool
```

增加“前置理由”展开区。不要重写现有概念定义。

### 5. 分支和回退

分支必须有理由：

```text
任务为什么能持续推进 → State Management
AI 怎样安全调用外部能力 → Permission Boundary
```

回退只回到最近的最小 `hard` 前置，不展示全部祖先。

## 五、关系处理规则

- `hard`：主路径默认前置；
- `soft`：可选补充，不强制；
- `support`：作为来源、案例、解释材料；
- `related`：放在相关概念，不进入当前主路径。

若当前数据没有 `support` 或 `related` 的统一字段，先根据现有字段映射展示，不要修改全量关系数据结构。

## 六、最小路线数据

可以在前端增加一份单独的 route fixture 或单独的路线配置，不要把路线顺序写回 `topics.json` 或 `dependencies.json`。

```json
{
  "routeId": "agent-continuous-action-v1",
  "title": "理解 AI 如何持续行动",
  "entryQuestion": "为什么 AI 能连续做事，而不只回答一次？",
  "target": "能解释 Agent 从目标到行动再到验证的基本循环",
  "steps": [
    {"conceptId": "agent", "order": 1, "type": "main"},
    {"conceptId": "tool", "order": 2, "type": "main"},
    {"conceptId": "agent-loop", "order": 3, "type": "main"},
    {"conceptId": "state-management", "order": 4, "type": "main"},
    {"conceptId": "agent-harness", "order": 5, "type": "main"},
    {"conceptId": "verification-loop", "order": 6, "type": "main"}
  ],
  "branches": [
    {
      "after": "agent-loop",
      "options": [
        {"conceptId": "state-management", "reason": "理解任务如何持续推进"},
        {"conceptId": "permission-boundary", "reason": "理解 AI 如何安全行动"}
      ]
    }
  ]
}
```

如果现有概念 ID 与示例名称不一致，以真实 `topics.json` 为准；不要猜 ID。路线配置中允许使用真实 ID 和中文展示名分离。

## 十、停止条件

出现以下情况时停止扩大范围并报告：

- 真实概念 ID 或依赖方向无法确认；
- 现有壳与本交接件描述不一致；
- 需要修改概念地图源数据才能继续；
- 需要新增 LLM 接口才能实现；
- 需要决定全量路线策略；
- 需要发布、push 或改变公网版本。

本轮的完成不是“把所有路径做好”，而是：

> 在现有知识体系网站里，让一条真实前置路径被看见、能走通、能回退，并且不破坏原有图谱探索。
