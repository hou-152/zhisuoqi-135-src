## 方向案：迭代档 `iterations/v5-plain-open/`（编号跳过 v4，避开并行会话在途的 v4-unify）

### 线 A · 全站黑话清扫（明面/台账双层）

- **原则一句话**：学习者明面说人话；内部口径不删，退到折叠区、数据层属性（data-*）、与 `CONTEXT.md` 台账。
- **黑话清单**（先成表再动刀）：`cm_*` `CON-*` `QST/CAS/OPI/SOL` `L0–L5` `CONCEPTUAL` 等类型枚举 `倒逼` `验收问句` `待验证区分度` `已激活` `superseded` `ready/scaffold` `verdict` `gaps` `四段就绪度` `主线锚点` `准入门`。
- **替换口径示例**：倒逼→「讲一遍，挑漏点」；验收问句→「怎么算会了」；待验证区分度→「这个反馈准不准，还没被真人验证过」；superseded→「这一讲在主线六章里」；L0–L5→不显示（台账保留）。
- **范围**：概念卡 → 路径条 → 知识树 → 实践空间（已做一半）→ 学习页残余 → 内参页 → 公网版同步（改文件 ≠ 发布）。
- **护栏**：黑名单做成断言（各面可见文本逐 token 扫），台账折叠里 token 原样保留——诚实不打折。
