## 对「知所栖 135」的直接可用结论

1. **三家的共同底线是"学习记录必须能整包带走"**：Anki `.colpkg`/`.apkg`（含排程与复习历史）、Mochi `.mochi`（ZIP+JSON，含 review history）、SuperMemo XML（含 `<LearningData>`）。三家都把"排程状态"当作可移植对象，而不是服务端私有资产。
2. **"云端存什么"是可以被官方明文写死的**：Anki 用一句 FAQ 说清 AnkiWeb 存"卡片文本 + 排程信息"、媒体单独存、限额 100MB/250MB。知所栖若要建立信任，同样需要一句这样级别的明文。
3. **对照组最锋利的一处**：Anki 本体（本地 + 免费同步）与 AnkiHub（第三方，隐私政策明写存"卡片内容 + 媒体 + **复习历史**，且默认公开、可用于统计与学术研究）是同一生态里两种截然不同的记录归属。这正是"学习记录归谁"的现成反面案例。
4. **Mochi 是可对标的正面结构**：免费档不限卡数、不限导出，`.mochi` 全保真（含 duration），Markdown/CSV 明确丢历史并**在官方文档里主动写明**，把同步/AI/API 放进付费墙。
