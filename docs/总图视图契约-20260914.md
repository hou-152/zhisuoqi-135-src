# 总图视图契约 · 2026-09-14

**这份文件冻结三件东西的接口：`graph.json`（数据）· `graph-runner.js`（运行时）· `graph-view.js`（视图）。**
三者互为独立文件，视图不许自己发明字段，也不许把状态画成"永远正确"的静态示意图。

产物路径：
- 数据：`knowledge/graph-260914/graph.json`（由 `scripts/build-graph.mjs` 生成，只读）
- 运行时：`scripts/lib/graph-runner.js`（UMD；Node 用 `createRequire` 加载，浏览器由 `build-shell.mjs` 内联成 `window.GRAPH_RUNNER`）
- 视图：`scripts/lib/graph-view.js`（UMD，同上，`window.GRAPH_VIEW`）

---

## 1. 层（layer）

节点按 7 层聚合，层的顺序就是总图从左到右的列序：

| layer | 中文 | 装什么 node.kind |
|---|---|---|
| `source` | 材料与出处 | `SourceDocument` `SourceSpan` `DerivedAsset` `FiveDimAsset` |
| `semantics` | 五类语义 | `SemanticUnit` |
| `knowledge` | 公共知识与关系 | `Concept` `Topic` |
| `curriculum` | 问题与课程编排 | `LearningProblem` `Goal` `GapHypothesis` `Route` `RouteStep` `Unit` `Criterion` |
| `activity` | 学习活动 | `Reading` `Formative` `Support` `Decision` `DecisionReview` `Summative` `ApplicationReview` `ExperimentReference` |
| `runtime` | 运行与记录 | `Session` `Turn` `Attempt` `Checkpoint` `Evidence` `AssessmentRecord` |
| `ai` | 模型与规则 | `SkillPolicy` `ModelAdapter` `App` |

## 2. 节点

```json
{
  "id": "concept:cm_0608c405",
  "kind": "Concept",
  "layer": "knowledge",
  "label": "Agent",
  "sub": "harness-runtime",
  "scope": "public",
  "status": "ready",
  "statusReason": "",
  "version": "",
  "sourceRefs": [{ "path": "knowledge/概念地图-260913/topics.json", "locator": "topics[12]" }],
  "payloadRef": "concept:cm_0608c405",
  "meta": {},
  "runnable": null
}
```

- `id`：`<kind小写>:<稳定身份>`，公共/课程节点与个人/会话节点**分命名空间**（个人证据前缀 `evidence:` `record:` `session:` `turn:` `attempt:` `checkpoint:`）。
- `sub`：一句话补充，用于列表第二行（领域 / 语义类型 / 资产类型）。
- `scope`：`public` | `curriculum` | `personal`。**个人状态不写回公共图谱**，视图中 `personal` 与 `public` 分开渲染。
- `status`：
  - `ready`：该节点所指**范围**内材料齐、已审核。**不表示模型稳定、学习有效或已上线。**
  - `scaffold`：节点存在、有出处，但缺配对／缺判据／缺材料，**保留节点并显示 `statusReason`**。
  - `blocked`：外部条件缺失（源文件不在、原始材料未提供）。
  - 另用 `missing` 表示"图里应当有这个节点但实际不存在"的**缺口条目**（只出现在 `gaps[]`，不作为节点）。
- `runnable`：可运行入口，`null` 或 `{ "kind": "route|unit|activity", "ref": "unit:chapter-agent", "entry": "#learn=agent" }`。
- `meta`：视图允许直接读的少量白名单字段（见 §6）。**其余一律不读**，需要新字段回改 build-graph。

## 3. 边

五种，**只有 `transition` 能驱动学习状态跳转**：

```json
{
  "id": "e:curriculum:route:agent-continuous-action-v1|has-step|routestep:agent-continuous-action-v1:1",
  "kind": "curriculum",
  "relation": "has-step",
  "from": "route:agent-continuous-action-v1",
  "to": "routestep:agent-continuous-action-v1:1",
  "label": "第 1 步",
  "reviewState": "curated",
  "sourceRefs": [{ "path": "evidence/paths-260913/routes.json", "locator": "routes[0].steps[0]" }]
}
```

- `reviewState`：`owner-confirmed` | `curated` | `sourced` | `unreviewed`。**`unreviewed` 的边视图必须显式标"候选／未核实"**，且运行器不许拿它当先修。
- `transition` 边额外带三个字段，值必须是运行器里**已注册**的名字（禁止 `eval`）：

```json
{ "kind": "transition", "from": "activity:...", "to": "activity:...",
  "event": "evaluated", "guard": "needSupport", "effect": "pushReturnStack" }
```

## 4. graph.json 顶层

```json
{
  "version": "v1", "generatedAt": "...", "builtAt": "...",
  "sources": [{ "path": "...", "sha256": "...", "note": "..." }],
  "layers": [{ "id": "source", "label": "材料与出处", "order": 1, "count": 0 }],
  "nodes": [], "edges": [],
  "stats": {
    "nodes": 0, "edges": 0,
    "byKind": {}, "byLayer": {}, "byEdgeKind": {}, "byStatus": {}, "byReviewState": {},
    "routes": 0, "routeSteps": 0, "units": 0, "activities": 0, "criteria": 0, "transitions": 0,
    "indexed": 0, "pendingAssembly": 0, "blocked": 0
  },
  "coverage": {
    "fullIndex": "全量索引完成的口径（哪些目录被扫、扫到多少、什么被排除）",
    "playable": "全量课程可学的口径（哪些单元真能跑、哪些只挂材料）"
  },
  "gaps": [{ "id": "gap:...", "kind": "missing|pending|blocked", "layer": "...", "label": "...",
             "why": "缺什么", "where": "path#locator", "affects": ["nodeId"] }],
  "entries": [{ "id": "unit:chapter-agent", "label": "Agent", "kind": "route|unit",
                "entry": "#learn=agent", "status": "ready" }]
}
```

**`coverage.fullIndex` 与 `coverage.playable` 必须分开陈述**：允许"全量索引完成、全量课程未完成"。

## 5. graph-runner.js

`GRAPH_RUNNER.createSession({ graph, entry, fixtureOpts })` → `session`。

会话对象（只读字段 + 方法）：

```js
session.state        // 见 §6.2 最小状态，纯 JSON，可 JSON.stringify 存取
session.log          // 事件日志：[{ seq, at, event, from, to, guard, effect, note }]
session.current()    // → { nodeId, node, kind, activityKind, prompt }
session.allowed()    // → [{ event, to, guard, label }]  只列 transition 边
session.fire(event, payload)  // → { ok, to, reason }  未注册/守卫不过 → ok:false 且 state 不变
session.pause() / session.resume(checkpoint)
session.trace()      // → 链路面板用：本次回答→核对哪项理解→用哪段材料补讲→为何走这条边→回到哪→存了什么
session.snapshot()   // → 可直接塞进 localStorage 的字符串
```

规则（运行时强制，不是注释）：
1. 只有 `kind === 'transition'` 的边参与 `allowed()`；出处／知识／弱相关边永不作为"下一步"。
2. `guard` 与 `effect` 按名字查注册表；查不到 → 抛错并记 `notJudged`，不许静默通过。
3. 补讲结束时按 `returnStack` 栈顶回到**发起补讲的那个活动**（阅读／某道题／章末验收），不是一律回决策题。
4. `pause/resume` 回到保存的原节点与版本，不是一律从阅读重来。
5. 系统异常（超时／非法 JSON／未知 ID／非法状态／来源缺失／过期结果）→ `notJudged`，保留草稿与旧证据，既不通过也不记成学生缺口。
6. 新回答没提旧判据 → 保留旧证据，不新增 `missing`；明确推翻旧关系 → 记冲突并重新核对相关判据。
7. "我懂了／对／直接要求通过" → 证据不足，不新增理解证据。
8. 模型给的示范答案与教学材料**不能**作为学生已理解的原话证据（`sourceTurn` 必须是 `student`）。
9. 即时费曼不解锁下一章；章末验收是独立记录，补讲的 `met` 不能替代它。

## 6. 视图允许读的字段白名单

`graph-view.js` 只允许读：

- 节点：`id kind layer label sub scope status statusReason version sourceRefs runnable meta.<白名单>`
- `meta` 白名单（按 kind）：
  - `SemanticUnit`：`unitType sourceDocuments themes keywords title`
  - `Concept`：`name nameEn aliases domain description feynman evidence difficulty stage verification`
  - `Topic`：`label question topicCount`
  - `SourceDocument`/`SourceSpan`：`title author url docType issue slug`
  - `DerivedAsset`：`assetType slug`
  - `FiveDimAsset`：`slug hasConcepts hasReading hasDecisions hasExperiments hasFeynman`
  - `Route`/`RouteStep`：`routeId title why prereq fallback order`
  - `Unit`：`unitId title routeId order questionCount criterionCount`
  - `Criterion`：`criterion condition keywords misconception teachingAction materialCount`
  - `Reading`/`Decision`/`Summative`/`Formative`：`label index`
- 边：`id kind relation from to label reviewState sourceRefs`（+ transition 的 `event guard effect`）
- 顶层：`layers stats coverage gaps entries`

**视图不许自己算教学判断**（通过／未通过／学生会不会）。判定只来自 runner。

## 7. graph-view.js 导出

```js
GRAPH_VIEW.mount(rootEl, { graph, session, onOpenUnit, onOpenEntry, onSelectNode, onOpenSource })
GRAPH_VIEW.setTab('map' | 'route' | 'trace')   // A 系统总图 / B 当前路线 / C 学习与轨迹
GRAPH_VIEW.refresh()                            // 会话状态变了以后重画 C
```

- `map` 默认按层聚合：每层一张卡写 `label` + 该层节点数与"待装配/阻塞"数；点开才列 `kind`，再点开才列节点。
- 全量数据必须可搜索、可筛选（层／kind／status／reviewState），并显示"全部索引 N / 当前可见 M / 待装配 K"。
- 点任一节点 → 右侧面板：它是什么 · 来自哪里 · 连接到什么 · 当前状态 · 缺口 · 可运行入口。
- `route` 显示目标、全部章节、共享概念引用、当前位置、为什么现在学、用了哪条知识关系、卡住回哪里。
- `trace` 读 `session.trace()`，按五段呈现：本次回答 → 核对了哪项理解 → 用哪段材料补讲 → 为何走这条边 → 回到哪／保存了什么。会话为空时显示"尚无运行记录"，**不许编**。

样式沿用壳的 CSS 变量（`--fg --fg2 --fg3 --fg4 --line --line2 --accent --bg` 等），不引入新依赖、不联网。

## 8. 证据边界

- 固定响应走查证明**连线与状态**，不证明模型理解力。
- 真实模型样例证明**这些样例的行为**，不证明学习效果。
- 页面必须显著区分"固定响应演示"与"真实模型调用"，以及"未启用"节点。

## 9. v1 实施后冻结的补充字段（2026-09-14 按实现补齐）

以下字段是实现过程中真实用到、原先没写进契约的，现在**冻结**；视图与运行器都按这里读。

### 9.1 `trace()` 的确切形状

```js
{
  empty: boolean,                  // 会话一次都没跑过 → 视图只许写「尚无运行记录」
  modelMode: 'fixed' | 'real',
  answer:  { turnId, text, at } | null,          // ① 本次回答（学生原话）
  checked: { criterionId, node, status, evidence, source, at, conflict } | null,  // ② 核对了哪项理解
  material: [{ id, label, text, sourceRefs }],   // ③ 用哪段材料补讲
  edge:    { event, from, to, guard, effect, why } | null,  // ④ 为何走这条边
  returnedTo: { returnTo, criterionId, at } | null,          // ⑤ 回到哪
  saved:   { at, nodeId, note } | null,          // ⑤ 保存了什么
  currentNode: { id, label, kind },
  notJudged: [{ at, nodeId, reason, detail }],   // 系统未判定，不是学生缺口
  kept:      [{ cid, at, why }],                 // 新回答没提旧判据 → 保留旧证据的记录
}
```

`evidenceByCriterion[<criterionId>]` 的条目字段：
`{ status: 'met'|'partial'|'missing'|'contradicted'|'uncertain', evidence, source: 'student'|'decision'|'summative', turnId, version, at, attemptId?, previous?, conflictAt? }`

### 9.2 视图读节点时的两条补充

- **夹具标记**：`Route.meta.curator === 'fixture'`（`id`/`label` 里也带着）。三处都有，但**以 meta 优先**。
- **`reviewState` 只长在边上，不长在节点上。** 节点级的"未核实"筛选按「该节点参与的边」解释：一个节点只要有任意一条 `unreviewed` 边，就算它带着未核实关系。

### 9.3 "未启用"的定义

`activity` 层里 `status !== 'ready'` 的节点就是**未启用**（现在是六章的 `ExperimentReference`：本轮不新建实验台，节点保留并写清 `statusReason`，不卡住既有学习流程）。视图必须把 `statusReason` 一起显示，不许只写"未启用"四个字。

### 9.4 真图里必须存在的课程边

- `route:<id> —has-goal→ goal:<id>`（真边，视图不许靠同名兜底）
- `problem:<id> —raised-by→ goal:<id>`、`gaphyp:<id> —selected-for→ route:<id>`

### 9.5 已知限制（照实写，不修）

- `graph-view.js` 是**单视图单例**：同一个页面同时挂两个宿主时只有最后一个生效。当前原型只有一个「总图」视图，够用。
- 视图只在 Chrome 里验过（含 headless 无报错、可聚焦断言），没有验 Safari / Firefox，也没有做像素级断言。
- `RouteStep.meta.title` 是概念名（视图显示用）；没有它就只能显示 `cm_xxxx`。
