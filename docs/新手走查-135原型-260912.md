# 新手走查：知所栖 135 原型（2026-09-12，真实浏览器全流程）

**怎么走的**：扮演第一次使用的新手，用真实 Chrome 点完整条链路 ——
首页 → 景别 → 1 阅读器（L1 → 确认理解 → 标记已读）→ 3 决策场（先选 C → 看案例 → 标准答案表 → 修订成 B）→ 5 实验台（推 / 拉 / 摇 试满 3/3 → 写结论）→ 费曼验收（**真实 API 检验**）。

截图证据：`output/playwright/01`～`05`。全程走的是 `node scripts/serve-135.mjs` 起的真实服务（`/api/health` = `llm:true`）。

## 一、走通的（演示可以放心的部分）

1. **主线不迷路**：1→3→5→费曼 每一步做完都有明确的「下一步」按钮，不用猜。
2. **决策场的闭环是真的**：先选 C → 案例与条件表告诉我零预算该走 B → 改成 B → 页面记下「你的决策轨迹：先选 C → 案例后修订为 B」。这个"被打脸再修订"的机制按设计工作。
3. **实验台有完成度约束**：必须试满 3 种运镜，完成即出现「进费曼演练室验收」入口。
4. **费曼验收真实跑通且质量高**：返回 `引擎：C1-pipeline(llm+live-search) · 证据：知乎实时检索`，逐条标出漏点（景别 △ 覆盖 1/3、运镜 ✓ 3/3），并给「回实验台补这个 →」。我故意只讲了一半，它抓出来了。

## 二、卡点（按演示风险排序）

### P0-1　首页两个引擎标识自相矛盾 ← 最该修

截图 `01`。**同一屏上**：顶部徽章写「轻量 Agent：真实检索 + LLM」（绿色），正文写「当前引擎：离线规则（未接 API）」。

**根因**（`prototype/知所栖-135-基础框架.html` 末尾）：

```js
route();        // 先渲染：此时 MODE.label 还是初始值「离线规则（未接 API）」
detectMode();   // 后探测：只更新顶部徽章，不重渲染正文
```

`detectMode()` 是异步的，完成后只改 `#mode-badge`，主页正文永远停在初始值，直到用户离开再回来。

**影响**：评委/观众打开首页第一眼就看到「未接 API」，会直接质疑「你们没接知乎数据」——而这恰恰是本次黑客松最该证明的事。

**修法**：`detectMode().then(route)`（一行）。

### P0-2　费曼验收等待期长且没有任何进度提示

实测两条：
- 页面内直接调用判定函数：**9.6 秒**返回；
- 点「开始检验」按钮那一次：**19:16:00 点击，19:16:30 仍未出结果**（>30 秒）。

等待期间界面只有按钮变成「检验中…」并置灰，**没有分步提示、没有进度、没有取消、没有超时**。

更硬的隐患：`serve-135.mjs` 的 `zhihuSearch()` 用 `spawn` 调 CLI，**只有 `close` 和 `error` 两条出路，没有超时**；浏览器侧也没有 `AbortController`。一旦某次请求挂起，按钮会**永久**停在「检验中…」，只能刷新页面。

**演示前建议**：① 按钮分步提示（「检索知乎证据 1/3…」→「AI 检验中…」）；② 加 30 秒超时兜底，超时走规则引擎并明说「已降级」。

### P1-3　点「进入」之后页面是空的

截图 `02`。进入「景别」后只有「1 阅读器 / 3 决策场 / 5 实验台」三个按钮，**没有默认选中的 tab，也没有一句引导**。新手会怀疑页面坏了。

**修法**：默认展开 1 阅读器，或加一行「先点 1 阅读器」。

### P1-4　决策场的进度会「跨概念自动涨」

我只从「景别」进入、只点了一次决策场，结果顶部三个概念全变成 `1/3`（景别还变成 2/3）。原因在 `pickCase2()` 里的 `CONCEPTS.forEach(c => state.case[c.id] = true)`。

从产品逻辑讲得通（决策场是一个全局情境，覆盖三个概念），但**界面上没有任何说明**，新手会困惑「我没学运镜，它怎么有进度了」。

**修法**：加一句文案（「决策场是全局情境，三个概念一起记」），或只在当前概念上记。

### P2-5　选了 C 的人，在标准答案表里找不到自己

我选 C（包装救场），第三步的条件表 4 行路线分别是 B / A / 长期根治 / 查流程，**没有一行回答「如果我就是选了 C 会怎样」**——C 的判定藏在最后的讲评里。

**修法**：表里补一行「若选 C：只遮盖、不解决信息节奏（讲评）」。

### P2-6　「下一步：5 实验台」跳到运镜，没有解释

我从「景别」进来，点下一步落到「运镜 · 技术实验台」。逻辑是对的（你刚选了"数字推镜"，去验证推镜），但页面没说明为什么换了概念。

## 三、一个没解释清楚的观察（照实记）

走查中同一页面出现过**两次读取按钮状态不一致**：一次读到「重新检验」且报告已渲染（截图 `05` 可见），另一次 snapshot 读到「检验中…」置灰。未能复现，原因不明。**可能是产品状态不稳，也可能是我这边抓取时机的问题**，不作为结论，仅留档。

## 四、结论

链路是通的、案例是真的、倒回机制真的能倒回去。**演示的两个坑都在 P0**：首页第一眼说「未接 API」，费曼环节可能静默等 30～40 秒。两条都是**一行级修复**，但都要动 `prototype/`，等你授权。
