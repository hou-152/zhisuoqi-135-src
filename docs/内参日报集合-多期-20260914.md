# 内参日报集合（多期）：上方日期条 ＋ 中间日报集合（2026-09-14）

## 一句话

壳的「内参」从**一期**变成**多期**：中间那一栏不再是某一篇的阅读页，而是**内参日报集合**
（按期倒序的每日日报）；日期选择在**上方**，点一篇才进单篇阅读。

## 起因（所有者原话）

> 「把昨天在 Readwise 上订阅的信息源，做三级笔记和概念提取，然后 push 到我的黑客松网站里面」
> 追问「推到哪一层」时，所有者改口径：
> 「在内参的二级页面中排一个日期选择功能，日期放在上方。中间的阅读位置替换为内参日报集合。」

## 形态（三层）

0. **顺序（第三版定的）**：日期 → 分类 → 标签 → 策展，而且**这四段住在中间那一栏（`#list`）里**。
   所有者先看了一版放在主区左侧的，指着中间栏那张篇目列表说：「把原本的这里替换掉，我指的是这个」——
   所以**中间栏不再是篇目列表**，改成这四段；**篇目在主区的日报卡里**（原来那 18 行 1./2./3. 列表撤掉）。
   筛选在我们真实数据上的落点：**分类＝条目类型**（文章／观点文／技术拆解／官方文档／行业观察／开源项目／
   商业观察／技能地图，带条数）· **策展＝重要等级**（★★★ 以上／★★★★ 以上，只留有信息量的档）。
   **「标签」那一组撤掉了**（所有者 2026-09-14：「标签我不知道，分类吧」）——它当时接的是来源域名，
   口径不确定就不摆。两组都能折叠（`▸/▾`，分类默认展开）、可叠加、可一键清空；中间栏头部计数跟着变。
1. **上方月历选日期**（第二版，2026-09-14 所有者给了 Readwise Reader 的截图：「类似这种吧」）：
   月标题 ＋ `‹ ›` 翻月 ＋ 周一开头的 7 列日格。**有内参的日子暖色点亮**（可点）、**选中的一天橙色**、
   没内参的日子灰掉；底下一行是 `全部 N 期 · M 篇` ＋ 状态提示（`已选 2026-09-12 星期六 · 10 篇` /
   `这个月 2 天有内参` / `这个月没有内参`）。点一天＝只保留那一天的日报卡。
   单篇阅读只用一条窄栏（`← 日报集合` ＋ 哪天第几篇），读的时候不摆整张日历。
   （第一版是横排日期片，被这张截图的口径取代。）
2. **中间＝内参日报集合**：按期倒序，一期一张日报卡（期号 · 日期 · 星期 · 篇数 ＋ 目录）。
   目录每行＝序号 · 主题 · 原标题 · 一句话主旨 · ★ · 「读 →」。
3. **单篇阅读**（没删）：从目录点进，仍是 三级笔记 / 概念网络 / 费曼 / 阅读原文
   （有拆解五维的那一期多一个「五维」签）；返回键放在日期条左侧，滚到哪儿都点得到。

左栏列表跟着选中那期走；「全部」时按期分组列全部篇目。
**默认停在「全部」**（`neiPeriod = ''`）——中间必须是集合本身，不能一进来就是某一期。

## 口径：昨天的信息源＝Inbox，不是 RSS 订阅流

| 口径 | 值 | 依据 |
|---|---|---|
| 日期窗口 | 目标日 `00:00–24:00`（Asia/Shanghai） | `lobster-daily` skill 的日期规则 |
| 严格筛选字段 | `saved_at`（**不看** `updated_at`） | 同上（`updated_at` 会把前一天保存、昨天更新的旧文误收） |
| 纳入 | `location = new`（手动存进 Inbox 的） | 同上 |
| 排除 | `location = feed`（RSS 订阅流） | 所有者选「8 篇 Inbox 精选」；订阅流是流水，一夜 70 条，与「我存了什么」不是一件事 |
| 留证 | 当期订阅流另存快照（`feedWindow`） | 让「为什么只做 8 篇」可事后追查 |

2026-09-13 当天实测：Inbox **8 篇** · 同期 RSS 订阅流 **70 条**（不纳入）。
快照：`evidence/内参-260913/readwise-原始返回.json`。

```sh

#   → knowledge/内参-260913/原文/<slug>.md（8 篇）＋ issue.json ＋ evidence/内参-260913/readwise-原始返回.json

#   → 三级笔记/ 概念辞典/ AI费曼/（note-taking-pro / concept-learning SOP 原文当 system prompt）
#   → 日报-260913.md ＋ 编辑日志.md（编辑日志是那一轮的记账）
node scripts/build-neican.mjs --issue 260913
#   → knowledge/内参-260913/内参-页面数据.json（真 LLM 元数据：主题/★/入选理由/隐喻/配色 ＋ 程序化 SVG 配图）
node scripts/cm-add-neican.mjs --issue=260913      # 概念并进地图（第四源的第二期）
node scripts/cm-build-map.mjs && node scripts/cm-build-wiki.mjs && node scripts/cm-wire.mjs && node scripts/cm-validate.mjs
node scripts/build-shell.mjs        # 全部期装成 DATA.neican.issues（新 → 旧）
node scripts/build-public.mjs       # → deploy/zhisuoqi-135/index.html（改文件 ≠ 发布，线上要 git push）
```

**一期一个目录、一份页面数据，互不覆盖**——`build-neican.mjs` 不给 `--issue` 时取最新一期。
