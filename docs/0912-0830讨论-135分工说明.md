## 四、模块 3 的一个未决问题（今天要拍）

**结论：知乎不进「判断依据」层。** 分工应该是：

| 层 | 谁承担 |

| 判断依据、理论、带条件的标准答案 | dbs-standard-answer + `research/` 里已核实的来源 |
| 问题入口（这领域的人在问什么、用什么词） | 知乎 —— **叙事性在这一层是优点** |
| 可核对锚点（可点、可查） | 知乎链接 |
