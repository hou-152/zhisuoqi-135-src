### ② 倒逼层 —— 概念图是个摆设

> 「变成了一个摆设，这是第一个点。第二点，概念其实也就那样吧。
> 这样子干你没法倒逼，当这种教学学习啊」

**摆设的源代码就一行**：

```js

```

**做了什么**
- 删掉自报通道。概念面板改成「遮住上面那句，用自己的话说一遍」→ LLM 判定 →
  给 `missing` / `wrong` / **`backTo`（漏哪倒回哪）**，`backTo` 只能指真实先修概念，渲染成按钮。
- 判定口径写死在提示词里：**照抄不算过、只写几个词不算过、「意思差不多」不放过、拿不准就 fail**。
- 三色环：青=复述过了 / 红=没过·倒回中 / **琥珀=只过机械检查（明确标注不算学会）**。
- 策展面板每条线加「开始倒逼 · 一步一个概念」，过了才给下一个。

**「概念其实也就那样」的正面回答**：同意。所以没有把概念做得更漂亮，而是**把概念清单从产品降成原料** ——

**落点**：`docs/倒逼层-概念图不是摆设-20260912.md`

原 10 条主题线是**主题聚类** —— 任何模型喂 194 条小标题都能吐一批，且不告诉你拿它干什么。
**更要紧的是它暴露了倒逼层的一个真 bug**：194 个概念用**同一个验收标准**（说清核心机制），
对「成本三因子公式」合理，对「第二次文艺复兴」是**假考**。

**做了什么**：`scripts/classify-concepts.mjs` → `evidence/concept-classes-20260912.json`，

| 类 | 条数 | 过的方式 |
|---|---:|---|

### ⑥ 桌面版 —— 「为什么不变成 app」

> 「为什么不变成 app」

**因为我把「必交件是链接」当成了「所以不做 app」——这是偷懒。** 所有者最早的原话是
「先做 APP 吧，如果可以的话；不行的话，再去做一个网站」。

**这一版不是换个壳**：网页版有两件事根本做不到，其中一件**正是我自己写进文档、标成「能力边界」的那条**：

| | 网页版 | 桌面版 |
|---|---|---|
| 学习记录 | localStorage，清一次浏览器数据就没了 | `~/Documents/知所栖-135/学习记录.json` |
| skill 产物 | `dbs-learning-beta` 的 SKILL.md **写死了**产物路径，网页版只能回「当前会话没有文件写入能力，先直接贴出」 | **真写文件**，那条路径第一次被兑现 |

**做法**：不重写第二份服务 —— `scripts/serve-lib.mjs` 是唯一一份，命令行壳（5180）与 Electron 壳（随机端口）都 import 它。

**打包踩的坑**：① `main.js` 原来 import `../scripts/serve-lib.mjs`，而 packager 只装 `app/` →
打出来的 `.app` **起不来且零报错**；② 不能把项目根当 source（`.private/` 会进可分发物）→
构建时加**凭证自检**，扫到 `llm.env` / `access-secret` / `*.key` 直接失败。打包版 `/api/health` 回 `llm:false`，**这是对的**。

**顺带修一个真缺陷**：`/api/save` 原来把路径里的 `..` **过滤掉**而不是拒绝 ——
`../../../../tmp/evil.md` 会被静默改写成 `DATA_DIR/tmp/evil.md` 写下去。它没跳出目录，
但**把一次越界尝试变成了一次成功的写入**。现在直接拒绝 + `join` 后再校验。

**落点**：`docs/桌面版-为什么要有它-20260912.md`

```sh
# 起服务（命令行版）
node scripts/serve-135.mjs              # → http://127.0.0.1:5180/知所栖-壳.html
# 起桌面版（能写真文件）
cd app && npm start
# 重新生成一切
node scripts/curate-concepts.mjs && node scripts/curate-edges.mjs   # 有缓存，改判据不重烧 token
node scripts/build-neican.mjs           # 内参一栏的数据（真 LLM 元数据带缓存；--force 重烧）
node scripts/build-shell.mjs            # → prototype/知所栖-壳.html
node scripts/build-public.mjs           # → deploy/zhisuoqi-135/index.html
node scripts/build-app.mjs              # → app/dist/知所栖 135.app
# 验收（全部要有 serve 在跑，test-app 除外）
node scripts/verify-135.mjs && node scripts/test-daobi.mjs
node scripts/check-public.mjs && node scripts/test-app.mjs
```

**铁律**（都有实测代价）：
1. 改了 `scripts/` 或 `prototype/` 就**跑一遍对应的验收脚本**，跑过再说话。
2. 无头 Chrome 抓不到 `transform` 过渡中的元素 —— **DOM 断言优先于肉眼读图**。
3. 测公网版**必须用假域名**（`--host-resolver-rules`），用 `127.0.0.1` 会走服务端那条路。
4. 判定/生成类的 LLM 调用**不要用固定 sleep**，轮询状态；通过侧断言要能重试。
5. 结论文件与代码冲突时，**以实测为准并报告冲突**，不擅自指定当前版本。
