# 概念网络图 · 产出规格 v1（2026-09-15）

本文件是「概念网络图」这一形态的**产出规格**（结构层）。改内容、改渲染、改 skill 都以它为准。
起因：所有者 09-15 02:0x 给了两套样例，要求把这种图在网站上全面、批量落地。

- 样例 1（分层架构）：Bengio《What can be done to mitigate loss-of-control risks》的 mermaid `flowchart TB`，
  五层 = 训练基础 → 目标与行为机制 → 风险放大机制 → 后果 → 缓解。
- 样例 2（顺序闭环）：「端到端 agent 工作闭环」，节点带短语标签（起点／长期形成／提炼终点／被揭示／回流下一轮／支撑／约束）。

## 一、一张图由什么组成

```json
{
  "version": "v1",
  "unitId": "route-agent-loop",          // 稳定 ID，文件名同此
  "unitKind": "route",                    // route（学习路线）| article（内参单篇）
  "title": "…",
  "generatedAt": "2026-09-15T…",
  "generator": "deterministic+llm",       // 谁产的：deterministic | deterministic+llm
  "reviewStatus": "generated-unreviewed", // 与仓库其它 LLM 产物同一口径
  "layers": [ { "id": "L1", "name": "训练基础" } ],
  "nodes":  [ { "id": "n1", "name": "预训练与人类模仿", "layer": "L1",
                "role": "core",           // core | linked
                "ref": { "kind": "cm", "id": "cm_xxx", "unit": "CON-xxx" } } ],
  "edges":  [ { "id": "e1", "from": "n1", "to": "n4", "label": "提供人类模仿基础",
                "basis": "quote",
                "quote": "……逐字原文……",
                "quoteFrom": "原文 · 第 42 句",
                "source": "narrative.links[0]" } ],
  "gaps":   [ "…没做成的部分，照实列…" ]
}
```

## 二、硬规则（每条都有对应的体检断言）

| # | 规则 | 为什么 |
|---|---|---|
| R1 | **只有 `basis: "quote"` 的边进图。** | 「不许编造关系」落到结构上，不靠自觉 |
| R2 | 每条 `quote` 必须能在该单元的原文／材料里**逐字**找到 | 边有原文依据；找不到 → 该边作废（不是改字） |
| R3 | `label` 是**短语**（≤ 14 字），不是整句 | 整句进不了图；整句放 `sentence` 字段供悬停/展开 |
| R4 | 边的两端必须是本图里的节点 | 断链在体检里算错，不算缺口 |
| R5 | `layers` 从基础到结果排列，`node.layer` 必须命中某一层 | 「分层／顺序」是这套图的一半 |
| R6 | 每层至少 1 个节点；每图至少 2 层 | 单层图不是网络图 |
| R7 | 概念地图能对上的节点填 `ref.id`（`cm_*`），对不上留空 | 点节点跳回地图；对不上照实留空，不硬凑 |
| R8 | `reviewStatus` 一律 `generated-unreviewed`，不写成「已审核」 | 模型产的没经负责人审核，不能升级 |

### 证据分级（照实标注，不混用）

| basis | 意思 | 进图？ |
|---|---|---|
| `quote` | 有逐字原文依据 | 进，实线 |
| `map` | 来自概念地图既有边（`note` 是策展/模型写的，**不是原文**） | 只作体检里的「待补原文」，**不进图** |
| `unverified` | 模型给了关系但引用过不了逐字校验 | **不进图**，进 `gaps` |

## 三、两套图的层怎么定

- **学习路线（六章）**：层 = 路线的 6 步，一步一层（Agent → 工具 → Agent loop → 状态子系统与进度持久化 → Harness → 验证闭环）。
  这是样例 2「顺序链路」的直接对应物；打开某一章时高亮该层。
- **内参单篇**：层 = 该文的论证结构（如样例 1 的五层）。层名由模型给，但必须落在原文的论证顺序上。

## 四、产出与落点

| 环节 | 文件 | 说明 |
|---|---|---|
| 生成 | `scripts/build-concept-net.mjs` | `--chapters` 确定性；`--articles <期>` 走 `/api/llm`，带缓存可断点重跑 |
| 数据 | `knowledge/概念网络-260915/<unitId>.json` | 一单元一文件；不动 `内参-页面数据.json`（那是 LLM 管线的产物） |
| 体检 | `scripts/check-concept-net.mjs` | 不需要 serve、不调模型；R1—R8 逐条断言 |
| 渲染 | `scripts/lib/concept-net-view.js` | UMD，`build-shell.mjs` 注入；`window.CONCEPT_NET` |
| 页面 | 内参单篇「概念网络」签 ＋ 学习空间章内 | 图在上，概念卡／正文流在下（原有内容一个不删） |

## 五、不许做的事

1. 不因为「图上有位置」就给一个没有原文依据的边。
2. 不把概念地图的 `note` 当原文引用。
3. 不在体检里放水：引用过不了就作废该边，不改判据。
4. 不把 `generated-unreviewed` 写成「已审核」或「已验收」。
