# 桌面版（Electron）：为什么要有它，它比网页版多了什么（2026-09-12 10:xx）

## 起因

所有者 09-12 10:0x 问：

> 「为什么不变成 app」

诚实回答：**因为我把「赛制必交件是链接」当成了「所以不做 app」，这是偷懒。**
所有者最早的原话就是「我让 Codex 去做一个 APP 吧，如果可以的话；不行的话，就去做一个网站」——
我先做了网站，然后就没有然后了。

## 为什么 app 不是「换个壳」而已

网页版有两件事**做不到**，而且其中一件正好是我自己写进文档、标成「能力边界」的那条：

| | 网页版 | 桌面版 |
|---|---|---|
| 学习记录 | 存浏览器 localStorage，**清一次浏览器数据就没了** | `~/Documents/知所栖-135/学习记录.json`，可备份、可搜索、可丢进别的工具 |
| skill 产物 | `dbs-learning-beta` 的 SKILL.md **写死了**产物路径 `~/Documents/dbskill-open-learning/<课题>/01.md`；网页版只能回一句「当前会话没有文件写入能力，先直接贴出」 | **真写文件**。那条路径第一次被兑现 |
| 知乎实时检索 | 跑不了（`scripts/zhihu` CLI 不在浏览器里） | 能跑 |
| LLM key | 访问者自己填 | 开发态读项目 `.private/llm.env`，本人不用管 |

所有者 09-12 05:09 那句「一个全量的概念树和自己的概念树才有意思，**因为保留它本地嘛**」——
**桌面版是这句话的落点。** localStorage 不算「保留在本地」。

## 做法的关键决定：不重写第二份服务

```
scripts/serve-lib.mjs        ← 服务本体（唯一一份）
   ├── scripts/serve-135.mjs ← 命令行壳，端口 5180
   └── app/main.js            ← Electron 壳，随机端口 + 窗口
```

两边 import 的是**同一个 `createZssServer()`**。修一个不会漏一个。
网页版、桌面版、公网版跑的是同一张 `知所栖-壳.html`。

## 打包踩的两个坑

### ① `.app` 打出来起不来，且没有任何报错

`main.js` 原来 `import '../scripts/serve-lib.mjs'`，而 `electron-packager` **只把 `app/` 目录装进包**——
那个文件根本不在包里。所以加了一个构建步骤 `scripts/build-app.mjs`，把
`serve-lib.mjs` 复制进 `app/lib/`，把页面与 skill 原文装进 `app/assets/`。

### ② 不能直接把项目根当 source

那会把 `.private/`（凭证）一起装进**可分发的东西**里。`AGENTS.md` 硬边界：
key 不进任何会被分发/提交的文件。

所以 `build-app.mjs` 里加了一道**自检**：装料之后扫一遍 `app/lib/` 与 `app/assets/`，
只要出现 `llm.env` / `access-secret` / `*.key` / `credentials` 就**直接失败退出**。

而且**打包版不内置 key**：`/api/health` 在打包版里回 `llm:false`，这是对的。
用户把自己的 key 放在 `~/Documents/知所栖-135/llm.env`（第一次启动会生成带说明的 `说明.md`）。

### 修掉的一个真缺陷

原来的路径消毒是「**把 `..` 过滤掉**」：

```js
.split('/').filter(s => s && s !== '.' && s !== '..')   // ← 旧写法
```

`../../../../tmp/evil.md` 会被**静默改写成** `DATA_DIR/tmp/evil.md` 写下去。
它确实没跳出目录，但它**把一次越界尝试变成了一次成功的写入**，调用方还以为写对了地方。
现在改成**直接拒绝**，并在 `join` 之后再校验一次解析结果仍在数据目录内。

## 边界（照实写）

1. **只打了 macOS arm64**。Windows / Linux / Intel Mac 都没打。
2. **没签名、没公证** —— 122MB 的 zip 发给别人，Gatekeeper 会拦，要右键→打开或
   `xattr -dr com.apple.quarantine`。要正式分发得买 Apple Developer 账号。
3. **体积 306MB 解包 / 122MB zip**。这是 Electron 的代价（内置 Chromium）。
   Tauri 能小到几百 KB，但**它要 Rust 工具链，这台机器没有**（`docs/本地优先与打包运行时-事实核查.md` 已核实）。
4. **没有自动更新**。
5. **没有 preload / IPC**：窗口走本地 HTTP，所以 `contextIsolation` 开着、`nodeIntegration` 关着，
   页面拿不到 Node——**这是有意的**，不是没做完。
6. **打包版里含 `.agents/skills/` 的 15 个 skill 原文**（381KB）。和公网版是同一个再分发问题：
   `dbs-*` 来自 dontbesilent 的 dbskill，若原作者要求移除，删掉 `app/assets/.agents/` 即可。
7. **`.app` 和 zip 都不入库**（`app/node_modules/`、`app/dist/` 已在 `.gitignore`）——
   122MB 的二进制不该进 git。要给别人就单独传。
