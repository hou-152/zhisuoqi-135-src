## 二、每条线给一条真实路线（不是模型编的）

每条线给三样东西：

| 字段 | 判据 | 例子（智能体工作流） |
|---|---|---|
| **从哪进** | 组内**没有前置**（入度 0）的点里，**解锁最多**（出度最大）的 3 个 | `harness 包裹 LLM`（解锁 6）· `用好 coding agent 是一项可拆解的技能`（解锁 2）· `把 AI 当数字员工`（解锁 2） |
| **路线** | 沿**真实依赖边**从入口走到收敛点，最长可达（边不够就短，**不编边**） | L0 用好 coding agent… → L1 三段高层工作流 → L2 关注点从代码转向规格与验证 → L3 可验证的分解 → L4 行为验证与功能验证 → L5 自主度校准 → L6 安全运行与权限闸门 → L7 确定性闸门 → L9 Lint 与门禁 |
| **收敛点** | 组内**被依赖最多**的 2 个 | `Lint 与门禁` · `精神时光屋` |

每一步标了是**骨架**（≥7 票、多次一致）还是**候选**（1–4 票、机器推的）。

## 三、266 条候选边：机器判了 250 条，只剩 16 条给人

生成器 `scripts/curate-edges.mjs`，产物 `evidence/concept-edges-curated-20260912.json`。

原来的左栏：「**265 条待你判**」。现在：「**16 条要你看（我自己判了 250 条）**」。

模型逐条给 `keep` / `skip` / `unsure` + 把握 + 一句理由，判断口径四条（写在脚本里）：

1. 「不先懂 B，A 就讲不通」—— 真前置 → 采纳
2. 只是同一个话题里挨着出现，谁先谁后无所谓 → 跳过
3. B 比 A 更抽象（概念图要「具体依赖抽象」）→ 跳过
4. 措辞相近、其实在说同一件事 → 跳过

结果：

| | 条数 |
|---|---:|
| 机器直接采纳 | **169** |
| 机器直接跳过 | **81** |
| **留给人看**（模型自己说 `unsure`） | **16** |
| `unsure` 比例 | 5.3% |
| 平均把握 | 0.618 |

**留人的口径是「模型自己说 unsure」，不是「把握低于某个阈值」。** 这一点踩过坑：
先用 `conf ≥ 0.7` 当阈值，结果 157 条模型其实判过的边被算成「没判」，
UI 上变成「机器判了 89 条，177 条不知怎么办」——**比原来更糟**。模型的把握刻度是 0.4–0.8 且用足了，
0.5 才是「接受一切非 unsure 判断」的正确阈值。

留给人看的 16 条按「影响大小」排序（跨篇优先、票数高的优先），每条旁边写着机器的猜测和把握，
**用户不看也不影响**，默认按机器判断走。250 条全写在证据文件里，**随时可查、可翻案**。

## 六、这一层**没做**的事（照实写）

1. **词表覆盖不均**：`不可替代` 只有 4 个主标签点，`智能体工作流` 41 个。提词表时要求过「每条 12–40 条」，
   模型没完全守住（相关数 17 与 67 越界）。**没有回去硬掰**——那是数据本来的形状。
2. **`数学与模型` 这条线偏窄**，几乎全部来自 S11 一篇（数学家丹尼尔·利特）。它的「相关 31」里有相当部分
   是「模型能力边界」这类被两条线共用的概念。
3. **边预判没有第二来源复核**。250 条是**一个模型跑一次**的结果，没有投票、没有第二模型交叉验证。
   置信度是模型自报的，不是实测的。**这不是已验证结论，是待复核的编辑判断。**
4. **没有「全量铺开」到 86 篇命中文章**。194 条概念只来自 12 篇（当时逐篇读 markdown 的额度限制）。
   如果要真·全量，得把剩下 74 篇的 `#### ` 也抄下来——那是另一次检索额度开销，本轮没做。
