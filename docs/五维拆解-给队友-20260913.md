# 五维拆解 · 给队友（2026-09-13）

**一句话**：五维 = 我们给每篇文章做的固定拆解 —— **概念 ×3 → 阅读 ×1 → 决策 ×3 → 实验 ×5 → 费曼验收 ×1**。
它就是产品主体「135」的展开，也是「知所栖」跟别的阅读工具真正不一样的地方。

## 一、五维各是什么

| 维 | 数量 | 它回答什么 | 资产字段 | 什么算过关 |
|---|---|---|---|---|
| ① 概念 | ×3 | 要读懂这件事，先得立哪三块砖 | `concepts[].name` ＋ `.points[]` | 概念辞典给得出「费曼一下」＋原文 quotes |

## 二、一维一条真实样例（整篇取自 `拆解五维/agent-skills-api`）

**① 概念 ×3** —— 代理技能（Agent Skills）／渐进式披露（Progressive Disclosure）／SKILL.md 与 YAML 前置元数据。
例：「每个技能都必须有 SKILL.md，含 YAML frontmatter，必需字段是 name 和 description。」

**② 阅读 ×1（三层梯度）**
- 直觉：把技能想成给新同事的入职指南 —— 平时只先交一张清单，真要做 PPT 才去翻对应手册。
- 机制：启动时只带 name 与 description（约 100 tokens/技能）；请求匹配后才用 bash 读 SKILL.md 正文。
- 边界：API 沙箱无网络、不能装包；自定义技能不跨产品面同步；Agent Skills 不在 ZDR 覆盖范围内。

**③ 决策 ×3** —— 每条都是「情境 / 做法 / 适用条件」三段。
例：*你在多个对话里反复粘贴同一套规范* → **做法**：打包成技能，description 同时写清「做什么」和「什么时候用」 → **适用条件**：任务反复出现、指导可复用、来源可信；一次性的特殊要求直接写在提示里更省事。

**④ 实验 ×5** —— 每条都是「做 / 观察 / 结论」三段。
例：*做*：建 `pdf-processing/SKILL.md` 与同目录 `FORMS.md`，手动走一遍读取路径 → *观察*：哪些文件被真正读取、哪些始终没被打开 → *结论*：验证按需文件访问，未引用的文件不消耗上下文。

**⑤ 费曼验收 ×1** —— 一段 AI 示范（30 秒版）＋ 3 条判定要点。
例：判定要点之一是「说清内容分阶段进入上下文：先元数据、触发后读指令、资源被引用时才读取；给出层级间的成本差异（元数据约百词、指令不足 5k、未访问资源为零）」。

## 三、为什么是 3 / 1 / 3 / 5 这个形状

1. **3 个概念**：概念是可复用的最小砖块。先立砖块，后面的阅读、决策才挂得住。
2. **1 段阅读**：给的是梯度（直觉 → 机制 → 边界），不是摘要。摘要省时间但不产生能力。
3. **3 个决策**：考的是「选」，不是「记」。决策场要的是先自己选、再看做法。
4. **5 个实验**：提取练习。做／观察／结论三段逼出证据，避免「看懂了」的错觉。
5. **费曼验收**：整套的限速器 —— 三个模块走完没复述不算完成；跳过记「未验收」，不记「未通过」。

## 五、现状：五维里只有 2 维上了页面（这条最要紧）

页面出口只有 4 个 tab：`三级笔记 / 概念网络 / 费曼 ×3 / 阅读原文`。

| 维 | 页面有没有出口 | 说明 |
|---|---|---|
| ① 概念 | 有（间接） | 「概念网络」取的是 `概念辞典/<slug>.md`，**不是** `拆解五维` 里的 `concepts` |
| ⑤ 费曼 | 有 | 30 秒版取 `feynman.demo`，验收版取 `feynman.rubric` |
| ② 阅读 | **没有** | `scripts/build-neican.mjs` 只读了 `dim.feynman`（327 / 340–343 行） |
| ③ 决策 | **没有** | 同上 |
| ④ 实验 | **没有** | 同上 |

**后果**：只看页面的队友会以为我们只做了「概念 ＋ 费曼」。要在 pitch 里讲五维，只能从资产层讲。
**要补的话**：给文章页加 3 个折叠块或 tab（读 `dim.reading/decisions/experiments` 即可），属于可逆改动。

## 六、别踩的三条

1. 五维内容是模型生成的，**结构校验过、内容未人工复核** —— 对外说「我们的拆解」可以，说「已核实的事实」不行。
2. 费曼有**三版**，别混：30 秒版 = `feynman.demo`；3 分钟版 = `AI费曼/<slug>.md`；验收版 = `feynman.rubric`（出处：`docs/内参一栏-AI内参格式-20260912.md` 第 21 行）。
3. 「五维」（本文，怎么教一个人）与「五类语义单元」（`docs/五类语义单元-给队友-20260913.md`，怎么组织材料）是两套东西，别当成一套讲。
