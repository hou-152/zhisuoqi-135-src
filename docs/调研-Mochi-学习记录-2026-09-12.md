## 3｜学习记录存在哪（本地优先 + 可选云同步）
- `[官方]` "Mochi is an offline first application. This means that every piece of content that gets added or changed is saved locally to your device first, before it is synced to the cloud." — https://mochi.cards/docs/getting-started/backing-up/
- `[官方]` 本地用户目录含：Content (Decks, Cards, Templates, etc)、**Review history**、Attachments、App settings、Login state (not password)。路径：Windows `%APPDATA%\Mochi`；macOS `~/Library/Application Support/Mochi`；Linux `$XDG_CONFIG_HOME/mochi` 或 `~/.config/mochi` — https://mochi.cards/docs/getting-started/backing-up/
- `[官方]` 本地库是 SQLite："the migration of local data from IndexedDB to SQLite … giving users a more open format for inspecting and querying their data locally." — https://mochi.cards/blog/v1-15-0-migrating-local-data-to-sqlite/
- `[官方]` 云端存储："Cloud storage — For synced cards, notes and attachments. Local only / 10 GB"（Free / Pro）— https://mochi.cards/pricing
- `[官方]` 服务端 API 基址 `https://app.mochi.cards/api/`；支付走 Stripe token — https://mochi.cards/docs/api/ ，https://mochi.cards/privacy
- `[官方]` 明确未加密："The data is not encrypted in the database." — https://mochi.cards/privacy
- `[官方]` 退订后数据保留："User-created data will be retained for up to 90 days after subscription ends."（2025-05-22 修改）— https://mochi.cards/terms
- `[官方]` 自述不担保数据："Mochi is not responsible for the loss of any user-created data." — https://mochi.cards/terms

## 4｜导出：能导出什么、什么格式
- `[官方]` **`.mochi`（原生，最完整）**："A .mochi export includes: Cards / Templates and fields / Attachments (images, audio, etc.) / Tags and metadata / **Review history** / Card order and deck structure"；".mochi files are simply ZIP archives containing a JSON file and attachments." — https://mochi.cards/docs/import-and-export/exporting/
- `[官方]` **Markdown**："Each card becomes a separate .md file." 警告："Markdown exports do not preserve metadata such as review history, card order, tags …, and templates." — https://mochi.cards/docs/import-and-export/exporting/
- `[官方]` **CSV**（2025-10-08 上线）："Pre-rendered: … two columns — 'Front' and 'Back.' / Not pre-rendered: Each field from the card's template is exported as its own column." 限制："All cards in the export must use the same template (or have no template at all)."；"the CSV export is mainly intended for compatibility with Anki. For transferring data between different Mochi accounts or backups, the recommended format is still the native .mochi export type." — https://www.mochi.cards/blog/new-browser-add-ons/
- `[官方]` CSV 警告："CSV exports do not preserve metadata such as review history, tags …, and templates." — https://mochi.cards/docs/import-and-export/exporting/
- `[官方]` **复习历史只有 .mochi 保留**："Export a deck as .mochi. A .mochi file preserves each card's full review history, including the date, due date, interval, and whether you remembered it. The Markdown and CSV export formats do not keep review history, so use .mochi specifically." — https://mochi.cards/docs/reviewing/fsrs/
- `[官方]` 两种导出入口：Settings → "Export everything"（全库 .mochi）；牌组菜单 → "Export deck"（单牌组 .mochi，含 "only that deck, its cards, template(s) and attachments"）— https://mochi.cards/docs/getting-started/backing-up/
- `[官方]` 导出**不限于 Pro**：定价对比表 "Import and export — Included / Included"（Free 也 Included）— https://mochi.cards/pricing
- `[官方]` 变更日志："Version 1.19.6 — October 8th, 2025 — New Features: Added a CSV export option (compatible with Anki)." — https://mochi.cards/changelog/
- `[官方]` **无 .apkg 导出**：.apkg 只出现在「导入 Anki」语境（"Import from Anki"，2019-10-07），导出页三种格式里没有 .apkg — https://mochi.cards/blog/ ，https://mochi.cards/docs/import-and-export/exporting/

## 5｜记录粒度
- `[官方]` "Every card has a review history, recording each time it has been reviewed in the spaced-repetition schedule. This history includes: Whether you remembered or forgot the card / The timestamp of each review / The intervals assigned / Duration of the review" — https://mochi.cards/docs/cards/
- `[官方]` 多份历史："if the Review Reverse setting is enabled, there will be a review history for the forwards version, and a separate review history for the reverse direction. Some cards can also contain multiple sets of Hidden text. In that case there will be a separate review history for each set." — https://mochi.cards/docs/cards/
- `[官方]` 归档保留状态："Archiving a Learned card will retain its learned state and review history." — https://mochi.cards/docs/reviewing/
- `[官方]` 卡片状态：New / Learned / Archived — https://mochi.cards/docs/reviewing/
- `[官方]` 默认算法按固定倍率调 interval；FSRS 模式额外建模 Stability 与 Difficulty，"FSRS derives each card's stability and difficulty from that card's existing review history" — https://mochi.cards/docs/reviewing/fsrs/
- `[官方]` 无 ease factor：打分只有二值 — "It records a review as either Remembered or Forgot"（无 Anki 的 Again/Hard/Good/Easy）— https://mochi.cards/docs/reviewing/fsrs/
- `[官方]` Review 对象字段：必填 `:date` `:due` `:interval` `:remembered?`，可选 `:duration` — https://mochi.cards/docs/import-and-export/mochi-format-reference/
- `[官方]` 卡片其余字段：`:content` `:deck-id` `:id` `:name` `:pos` `:reviews` `:fields`（另有 templates/fields/decks 结构）— https://mochi.cards/docs/import-and-export/mochi-format-reference/
- `[官方]` **公开 API 存在且仅 Pro**："API keys — Read and write your cards from the HTTP API. Not included / Included" — https://mochi.cards/pricing
- `[官方]` API 资源对象：Cards（`content`/`deck-id`/`template-id`/`archived?`/`review-reverse?`/`pos`/`manual-tags`/`fields`/`tags`/`references`/`reviews`/`created-at`/`updated-at`/`new?`）、Decks、Templates，加 `GET /due` 与 `GET /due/:deck-id` — https://mochi.cards/docs/api/
- `[官方]` `GET /due` 返回的 card 含 `reviews: [{date, due, remembered?, duration}]` — https://mochi.cards/docs/api/
- `[官方]` 认证：HTTP Basic Auth，API key 作用户名；并发限制每账号 1 个并发请求，超限 429 — https://mochi.cards/docs/api/
- `[官方]` `/due` 端点 2025-10-28 上线；API 限流改为每用户同时 1 请求 — https://mochi.cards/changelog/

## 是否支持导出 / 是否有限制
**支持，且免费档就能用。** 三种格式，保真度递减：
1. `.mochi`（ZIP+JSON）——**最完整，含复习历史**、模板与字段、附件、标签与元数据、卡片顺序与牌组结构。跨账号迁移与备份的官方推荐格式。
2. Markdown（每卡一个 .md，ZIP）——**不含复习历史**，也不含卡片顺序、模板、标签（除非标签写在正文里）。
3. CSV——**不含复习历史**，不含模板与标签；且要求整包卡片使用同一模板（或无模板）。

**明确限制：只导出卡片正文、不含复习历史/排程状态的路径就是 Markdown 与 CSV；要带走复习历史（date/due/interval/remembered?/duration）必须用 `.mochi`，或用 Pro 的 `GET /api/cards`、`GET /api/due`。** 无 `.apkg` 导出。

## 未核实清单
1. **Pro 按月计费的单价**：定价页只有 "Pay monthly / Pay yearly" 切换，实抓文本只渲染出 `$5 per month`（按年计费口径）；月付口径的具体数字未核实。
2. **云服务供应商与机房地区**：隐私政策与条款均未点名任何托管商（仅提到支付走 Stripe）；服务器厂商/地区未核实。
3. **FSRS 的 Stability / Difficulty 是否作为字段持久化**：文档只说是 "derives … from that card's existing review history"；导出格式与 API 里都没有这两个字段，是否落库未核实。
4. **纯离线（无账号）状态下能否使用「Export everything」**：定价页只写 Free 档 "Import and export — Included"，未明确说明该导出是否需要登录；是否需要账号未核实。
5. **单牌组 `.mochi` 导出是否含复习历史**：backing-up 文档在单牌组路径只列了 deck/cards/templates/attachments，未列 review history（总述的 .mochi 描述则含 review history）；单牌组路径未核实。
6. **第三方独立审计**：未找到任何第三方对上述存储/隐私说法的独立验证。
7. **官方论坛中关于导出的权威帖**：forum.mochi.cards 可访问（Codidact 搭建，HTTP 200），但其搜索接口返回 404，仅首页列表可见（可见帖含 `.mochi` 附件引用、iOS 导入 .mochi/.apkg/CSV 报错等），未取到导出主题的官方权威帖。
