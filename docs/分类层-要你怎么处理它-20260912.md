# 分类层：不问「这讲的是什么」，问「这个概念要你怎么处理它」（2026-09-12 09:xx）

## 所有者指出的是什么

> 「概念分类一般吧，我觉得」

原来的 10 条主题线（人机分工 / 智能体工作流 / 理解优先 / 不可替代 / 一人企业 /
组织边界 / 产品判断 / 验证优先 / 学会学习 / 数学与模型）——**一般，是对的**。因为：

1. **它是「这讲的是什么」**，是主题聚类。任何模型喂 194 条小标题都能吐一批，**没有壁垒**。
2. **它对学习没用**。知道「四象限属于人机分工」不告诉你该拿它干什么。
3. **标签边界是糊的**：194 条里 184 条多标签，人机分工 37 条、智能体工作流 67 条，互相咬。
4. **它把一个图谱最值钱的东西扔了**——结构。它只有桶，没有层次。

## 更要紧的：上一版有个真 bug

倒逼层刚建好时，**194 个概念用的是同一个验收标准**：遮住原文，说清它的核心机制。

这对着「成本三因子公式」是合理的；对着**「第二次文艺复兴」**就是**假考**——
那是一个时代命名，没有机制可复述，也没有对错。硬让人"说清它的机制"，
得到的要么是背诵，要么是编。

**这是分类该解决的问题：不是把概念分堆，是决定拿它怎么办。**

## 改成了什么

生成器 `scripts/classify-concepts.mjs`，产物 `evidence/concept-classes-20260912.json`。
判据只有一句话：**这个概念该要求学习者做到什么，才算学会了？** 四选一。

| 类 | 条数 | 过的方式 | 系统对你做什么 |
|---|---:|---|---|
| **能算的** | 69 | 复述核心机制 + 不违反事实 | 遮住原文，说清机制；漏机制/说错/照抄 → 没过 |
| **能判的** | 57 | 说出**你自己的判据和代价** | 只复述原文 → 没过；说「看情况」不给判据 → 没过；没提代价 → 没过 |
| **能用的** | 27 | 给一个**你真拿它做过的具体例子** | 只有定义没有用例 → 没过；用例含糊或像编的 → 没过 |
| **只能认的** | 41 | **不设验收** | 没有交卷框，只有「我读过了」。**硬考它就是假学习，所以我们不考** |

分类的 `why` 也一起落盘，每条 12–28 字，说清**凭什么这么判**。抽样：

| 概念 | 判成 | 凭什么 |
|---|---|---|
| 纯粹派（the purists） | 只能认的 | 一个类型命名，无可检验机制，只有人物画像与立场 |
| 第二次文艺复兴 | 只能认的 | 时代命名，既无机制可复述也无对错 |
| agent 即实习生 | 只能认的 | 把 agent 当实习生，是比喻式命名 |
| 四象限与整合理论 | 能用的 | 威尔伯四象限是可拿去定位的具名框架 |
| 判断 AI 需求的三问 | 能用的 | 三问是可直接拿去筛需求的具名清单 |
| 成本三因子公式 | 能用的 | 调用量乘 token 量乘单价，可直接拿去算 |
| 技能树的互联性 | 能判的 | 该不该多线并进取决于你算过的代价权衡 |
| 线性职业 vs 指数职业 | 能算的 | 线性与指数职业的机制差异可复述并检验 |
| AI 只擅长已知信息 | 能算的 | 关于模型能力边界的机制断言，可复述可检验 |

**关键的一条判据写进了提示词**：「不要因为『它是个观点』就丢进只能认的——
如果这个观点后面跟着一套判据，它是能判的。」

## 界面上的表现

- **默认横轴换成这四列**（「按主题」「按来源」两档都还在，三档可切）
- 概念面板顶部标出它属于哪一类 + 凭什么
- 倒逼区按类换任务词：
  - 能算的 → 「遮住上面那句，用自己的话**说清它的机制**。」
  - 能判的 → 「它给的是什么判据？**换成你的处境你会怎么用？代价是什么？**」
  - 能用的 → 「它是什么？**给一个你真拿它做过的具体例子**（做了什么、结果如何）。」
  - 只能认的 → **没有输入框**，只有「我读过了」
- 左栏四态：过 N / 没过 M / 读过 K（不考）

## 公网版

同一份代码。无模型时走机械兜底，并且**按类区别对待**：

- `能算的` → 关键词覆盖检查，最多给琥珀环（`mech`，标注「没经语义判定」）
- `能判的` / `能用的` → **直接按没过记**。因为「你自己的判据」和「你真用过的例子」
  **关键词覆盖检查根本看不见**，给它琥珀环就是把「词提到了」冒充成「判据给了」。

**宁可说没验过，也不给假绿。**

## 这一层**没做**的事（照实写）

1. **分类是模型单跑一次**，没有第二来源复核。我只手工抽查了 9 条（上表），看着都站得住，
   但**没做全量人工审计**。
2. **边界仍然有人会不同意**。「一人企业」被判成 `judge`（要不要走一人企业是取舍），
   但也可以说它是 `accept`（一种叙事）。**这类分歧没有被记录、没有被处理**——
   文件里只存了模型那一次的判断和理由。
3. **没有让学习者改判**。你觉得某条判错了，界面上没有「这应该是另一类」的按钮。
   目前只能改 JSON 重跑构建。
4. **「只能认的」不设验收，是一个编辑判断，不是研究结论**。它的依据是推理
   （没有可检验内容就不该考），不是实验。**不得对外声称「不考世界观更有效」。**
5. **10 条主题线没删**。它现在是「按主题」那一档，用来跑策展路线；
   它作为分类一般，作为**路线的骨架**还行——这两件事这轮没有分开评估。
