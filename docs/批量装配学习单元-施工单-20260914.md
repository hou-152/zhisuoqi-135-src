## 1. 这一轮做什么（**不许调模型、不许造内容**）

**目标：把 76 个 CON 批量装配成可运行的学习单元，并让它们走同一份 `graph-runner`。**

每个 CON 一个单元，材料**全部逐字来自已有已审计产物**：

| 单元字段 | 取自 | 硬要求 |
|---|---|---|
| `concepts[0]` | CON 单元的 `title` + `key_fields` | 逐字 |
| `reading.original` | 对应图鉴卡的 `source_context` | 逐字，必须能在卡里 `indexOf` 到 |
| `reading.explain` | 卡的 `remember` | 逐字 |
| `reading.intuition` | 卡的 `feynman` | 逐字 |
| `reading.mechanism` | 卡的 `how_to[]` 拼接 | 逐字，逐条 |
| `reading.boundary.items` | 卡的 `boundaries[]` | 逐字，逐条，不合并改写 |
| `qst` | 反向 QST 单元 | 引用 ID |
| `case` | 反向 CAS 单元（`type` 照实带，全部是「假设场景」） | 引用 ID，**不许写成真实复盘** |
| `solution` | 反向 SOL 单元 | 引用 ID |
| `opinions` | 反向 OPI 单元（57 个没有 → 空数组 + 缺口） | 引用 ID |
| `feynman.checks[]` | **卡的 `boundaries[]` 一条一条当判据**：`point` = 该条边界的前 12 字，`condition` = 该条边界全文，`misconception` = 该边界的反面转述（**必须标 `derived`，不许标 `authored`**） | 逐字 |

**决策题这一轮一律不生成**，每个单元写一条缺口：
「该单元的三道决策题待装配：批量装配不补造唯一正确答案（任务书 §2.3）。可用素材已经就位：CAS 情境、SOL 动作路径、该卡 boundaries 的误区清单。」

理由写进缺口里，不要留空。
