# 使用说明

这个目录是「知所栖 135」的**决策工程**，不是文档库。文档真源仍在项目根目录。

## 四层各管一件事

| 层 | 放什么 | 规则 |
|---|---|---|
| `01_事实/` | 发生过什么。客观事实、相关方笔记、长期偏好 | 只追加，不改已有条目 |
| `02_规律/` | 看出什么。从多次事实里炼出的概念和模式 | 缓慢追加修正，原段不重写，用 `[修正 YYYY-MM-DD]` 追加 |
| `03_定格/` | 某时整体什么样。状态画像、事件诊断、专项快照 | 写完不改，情况变了新建带新日期的 |
| `04_待解/` | 还没想清楚的。开放问题、待验证假设、观察指标、决策事件 | 完成即清，答案回流 01 或 02 |

## 怎么用

**只读一个文件**：`我的当前状态.md`。里面的「当前最强矛盾」是一张待裁决表，Codex 读它就能接手。

**每条的状态**：

- 决策事件：`待裁决 / 已裁决 / 已执行 / 已推翻`。「已裁决」= 所有者拍过板；「已执行」= 改动已落进源文件；「已推翻」= 后来推翻了。
- 执行事件（事实唯一、不需要拍板的）：`待执行 / 已执行`。

## 三条纪律

1. **不替所有者裁决。** 没拍到板的一律 `待裁决`。
2. **每条要能指到路径与行号**，核不到的写「未核实」。
3. **来源分三类标出来**：`[本人]` 原话 / `[文件记载]` / `[AI 判断]`。
