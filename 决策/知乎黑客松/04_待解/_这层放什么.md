# 这层放什么

**放**：还没想清楚的——开放问题、待验证假设、观察指标、关键决策事件。

**不放**：已经拍板的决定（回流 `01_事实/` 或 `02_规律/`）、已经在跑的执行细节。

规则：**完成即清。** 答案回流到 01 或 02，原条目移除或标「已完成」。

## 决策事件什么时候立

命中任一条就立：① 涉及产品结构变化；② 涉及重大合作变化；③ 涉及价格带变化；④ 涉及长期策略反转；⑤ 后续明确需要结果回填。

**一条矛盾 = 一个文件。** 纯计数错和登记缺口不必各立一个（见 `决策事件_2026-09-12_计数修正与登记缺口.md` 的合并说明）。

文件名：`决策事件_YYYY-MM-DD_标题.md`
状态取值：`待裁决 / 已裁决 / 已执行 / 已推翻`
