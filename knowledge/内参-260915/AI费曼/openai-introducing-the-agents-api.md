这篇文章问：要把玩具 AI 变成能连续干几天活的云端员工，需要什么？OpenAI 发布的 Agents API 给出的回答是：把 Codex 托管执行框架开放给开发者。

核心机制在于“分工与压缩”。Agents API 托管了三件事：第一，长会话快满时自动压缩历史记忆；第二，按需动态检索工具并用代码直接串联调用，防止原始数据撑爆上下文；第三，一键派生多个子智能体并行干活，主智能体负责最终汇总。沙箱环境则与执行框架解耦，支持自有 VPC。

日常生活类比：这就像从雇佣一个时刻盯梢的零工，升级为采购了一套带办公室、副手团队和档案压缩系统的自动化项目部。

作者承认的代价：多智能体与长程沙箱虽然提效，但完全随 Token 消耗量计费，高并发可能带来突发账单。
