这篇文章问：Agent 怎么从用户的日常挑刺中自动变聪明，而不用人工天天改 Prompt？Warp 借 Claude 给出的答案是：双技能自进化循环。

核心机制在于内外两层技能分工。内层技能是业务底稿（如审查代码规范）；当用户在 PR 评论区留下具体纠错时，外层“改进者技能”会定期巡视，把所有反馈捞出来，对比最初建议与人类评价，自动向内层技能提一个极小的修改 PR。人类工程师点个 Approve 合并，下次运行就自动掌握新规矩。

日常生活类比：这就像新学徒拿一本活页手册干活，师傅随时在边角批注；每天下班，专门的书童把所有批注精炼后替换掉手册里旧的那一页。

作者承认的边界：不能让 Agent 盲目吸收所有反馈（用户可能是错的），必须严格限制只有资深领域专家的反馈才算数，最终合并也必须由人类最终把关。
