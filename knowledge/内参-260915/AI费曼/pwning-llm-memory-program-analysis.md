这篇文章问：AI 助手在长程漏洞分析时，老是忘记之前的假设已被推翻，依然基于错误前提胡说八道，怎么破？安全研究员用程序分析思路做出了 Lemmalog：用 Datalog 逻辑引擎接管模型记忆。

核心机制在于“模糊与确定性分离”。让大语言模型只做擅长的模糊翻译：把杂乱的调试日志和代码提炼为结构化“事实”；逻辑推导全部交给底层的 Datalog 规则引擎。一旦某个事实被调试证伪（如指针未对齐），引擎沿着因果溯源树（Provenance），自动将所有基于该事实派生的假结论一次性撤销（Retraction），根本不需要模型在上下文里反复自我纠缠。

日常生活类比：这就像侦探只负责录入证词线索，墙上的案情线索板由电脑连线；只要抽掉一张假纸条，挂在这张纸条下的所有推论全会自动掉落。

作者指出的边界：逻辑引擎无法阻止模型在最初提取事实时产生幻觉，但能确保未经证实的推论绝不可能在系统状态中无声蔓延。
