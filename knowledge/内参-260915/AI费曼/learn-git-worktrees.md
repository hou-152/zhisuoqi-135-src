这篇文章问：多个 AI 助手同时在一个代码库干活，怎么保证互不打架？ChatGPT Learn 的解法是：自动化 Git Worktree。

核心机制在于“分身隔离”。Git 树干元数据只有一份（共用 .git），但在后台可以克隆出多套独立工作区。Codex 为每个后台对话分配独立目录，默认以游离头指针（detached HEAD）运行，既不抢占分支名，也不弄脏前台代码；通过 Handoff（交接），随时把后台代码拉回前台。配合 .worktreeinclude 文件，还能把被忽略的环境变量（.env）自动复制过去。

日常生活类比：主厨在总厨房记一本总账，同时在隔壁开好几张独立案板给帮厨；大家看同一本食谱，但各切各的菜，绝不撞板。

作者承认的代价：多分身成倍吃硬盘空间，系统默认上限保留 15 个，超期自动归档快照。
