# 执行主体从人变成 Agent

> 流程步骤不变，但分析、设计、编码、调试的执行者由人变成 Agent。

**领域** agent-org ｜ **类型** CONCEPTUAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.198

## 费曼一下

流程步骤没变，但具体做分析、设计、编码、调试的人不再是人，而是 Agent。人升到指挥官位置。这个概念承重，因为后面讲的确认合并、文档桥梁、瓶颈转移，都是执行主体改变后的结果。

## 原文 context

变的是什么？执行主体。

> 以前每个环节都是人亲手干。现在，人变成了指挥官，Agent 变成了执行者。人只在关键路径上做确认和决策，但具体的分析、设计、编码、调试，全部交给 Agent 去执行。

- 能指出人变成指挥官、Agent 变成执行者
- 能把确认合并、瓶颈转移等现象归因于执行主体改变
