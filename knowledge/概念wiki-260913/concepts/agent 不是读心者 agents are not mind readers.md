# agent 不是读心者 · agents are not mind readers

> agent 不读心，只能靠上下文变得有用——这条第一性原理推出上下文是新系统的核心。

**领域** context-engineering ｜ **类型** CONCEPTUAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.072

## 费曼一下

再聪明的助手，你不告诉它来龙去脉，它也帮不上忙。agent 不会自己猜出你的目标、约束和历史决策，你得把这些信息喂给它。所以问题不在于 agent 够不够聪明，而在于你有没有把上下文摆到它面前。

## 原文 context

新范式的第一性原理——"agent 不是读心者。它们通过上下文才变得有用（Agents are not mind readers. They become useful through context）"。这句话直接推出"上下文"为何是新系统的核心。
