# 上下文失败，而非模型失败 · context failures, not model failures

> 多数 agent 失败已不是模型能力不够，而是上下文装配不对，修系统比换模型更有效。

**领域** context-engineering ｜ **类型** CONCEPTUAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.042

## 费曼一下

助理办错事，先别急着换人。多半是你没告诉他日程满了、没给他通讯录、没给他发邀请的权限。同一个人，材料给全了，表现就换了一个档。

## 原文 context

全文最有力的归因判断，出现两次——「大多数 agent 的失败已经不再是模型失败，而是上下文失败」「agent 的失败不只是模型失败；它们是上下文失败」。它是从「换个更强的模型」转向「修好装配上下文的系统」的开关。

## 掌握证据（做到这些才算会）

- 能把一次失败归因到上下文装配而非模型
- 能据此提出改装配方案而不是换模型
