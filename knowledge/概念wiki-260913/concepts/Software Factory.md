# Software Factory

> 长时间运行的 Agent 覆盖软件生命周期，企业把 repository 与阶段流程自动化，只保留人工检查点。

## 费曼一下

把写、测、审和部署组织成 Agent 生产线，但每家公司仍要决定哪些工位全自动、哪些必须人签字。

## 原文 context
