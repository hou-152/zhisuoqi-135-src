# 本地状态层

> Claude 把 TODO、会话消息与统计缓存放在 ~/.claude 下的本地存储层。

**领域** state-persistence ｜ **类型** REPRESENTATIONAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 只能认 ｜ **中心度** 0.192

## 费曼一下

agent 不只是一次性对话，它需要一层落在磁盘上的记忆——待办、历史消息、摘要、实验开关。看一个 agent 在你机器上留下了什么文件，就知道它把什么当成需要跨会话保留的东西。

## 原文 context

TODO list 不在项目路径下，而在 \~/.claude：todo 是 json，另有 sqlite 数据库 \_\_store.db 存放消息（含 conversation_summaries 等表），还有 statsig 的缓存文件。
