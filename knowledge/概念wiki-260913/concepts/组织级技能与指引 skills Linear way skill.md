# 组织级技能与指引 · skills / Linear way skill

> 产品内置分组织级与个人级的技能与指引，如“Linear way skill”让 agent 按固定格式把功能请求综合成可讨论、可执行的东西。

**领域** agent-org ｜ **类型** REPRESENTATIONAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能用 ｜ **中心度** 0.017

## 费曼一下

技能就是把“我们这家公司是怎么想事情的”写下来、喂给 agent，让它像一个懂行的老员工那样开口，而不是一个只会通用套话的外人。你把团队的判断口径、常用格式、看问题的顺序固化成一份可复用的“上岗手册”，agent 一加载就自带你们的品味——这比每次临时提示要稳定得多。

## 原文 context

Linear 演示中的功能——在产品里内置 skills，分组织级指引和个人级指引。Karri 亲手做了个“Linear way skill”：喂进公司 blog 里关于产品开发的材料，让 agent “act like a linear product teammate”，并按固定格式（从“底层需求”开始）去综合功能请求，比如把“多人指派同一 issue”“multiple workspaces”这类几百人提的诉求，变成可讨论、可执行的东西。

## 掌握证据（做到这些才算会）

- 能说出组织级指引与个人级指引的区别
- 能按固定格式从底层需求出发综合功能请求
