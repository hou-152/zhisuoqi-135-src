# 仓库即唯一事实来源

> 一切指令、状态与清单必须以文件形式落进仓库，否则对 agent 不存在。

**领域** context-engineering ｜ **类型** CONCEPTUAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.117

## 费曼一下

团队里的默契、走廊上的口头共识、某个人脑子里的历史包袱，对 agent 全是虚空。它的世界边界就是它能读到的文件——所以想让它知道的事，都得写进仓库。

## 原文 context

L03 的主张，判据是那句「**agent 看不到的东西，对它来说就不存在**」。它解释了为什么指令、状态、功能清单必须以文件形式落在仓库里，而不是留在人的脑子里、聊天记录里或口头约定里。

## 掌握证据（做到这些才算会）

- 能复述「agent 看不到的东西就不存在」这一判据
- 能把口头约定改写成仓库里的文件

## 验收问句

> 按 {{name}}，为什么口头约定对 agent 等于不存在？

## 懂了它才能懂（解锁 4）

- [[上下文骨架]] — 骨架把信号与决策落成文件才成立，不先认仓库为唯一事实来源就无从谈骨架。
- [[Codified Context]] — 把隐性约定写成入库文档，前提是承认仓库才是唯一事实来源。
- [[Repo-local instructions]] — 仓库内规则文件可反复读取的前提，是仓库对 agent 才是唯一事实来源。
- [[docsdecisions]] — ADR 落盘使“为什么”也进入仓库，强化仓库作为唯一事实来源。
