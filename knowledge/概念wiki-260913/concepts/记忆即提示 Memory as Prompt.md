# 记忆即提示 · Memory as Prompt

> 把记忆当作一种提示来管理：写入什么、何时注入上下文，都由提示工程的原则决定。

**领域** memory-retrieval ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.035

## 费曼一下

记忆不是事实本身，而是给模型的线索。Agent 不能盲信记忆，行动前仍要用当前环境验证它是否还成立。

## 原文 context

“记忆视为一种‘提示’”

## 掌握证据（做到这些才算会）

- 能把一条记忆改写成可直接注入的提示片段
- 能判断哪些记忆值得写入、哪些是噪音

## 验收问句

> 既然 {{name}}，这条记录该怎么写才在被取回时管用？
