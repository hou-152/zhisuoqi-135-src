# Resolver

> 上下文的路由表：任务类型 X 出现就先加载文档 Y；skill 说怎么做，resolver 说加载什么、何时加载。

**领域** context-engineering ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能用 ｜ **中心度** 0.035

## 费曼一下

resolver 是「何时加载哪份文档 / 哪个能力」的路由器。

## 原文 context

> A resolver is a routing table for context. When task type X appears, load document Y first.

## 掌握证据（做到这些才算会）

- 能写出「任务类型→加载文档」的映射表
- 能区分 resolver 管加载什么、skill 管怎么做

## 验收问句

> 遇到某类任务时，{{name}} 决定先加载什么？
