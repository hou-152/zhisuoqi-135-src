# 可执行搜索空间

> 一旦 harness 设计成为可执行的搜索空间，强 coding agent 就能在远超手写 prompt 的同一片设计空间里搜索。

**领域** harness-runtime ｜ **类型** CONCEPTUAL ｜ **什么时候学** 深入研究再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.042

## 费曼一下

只要一个东西能写成代码、还能自动打分，它就能被机器一遍遍试着改。把 harness 写成代码，就等于把设计工作交给了会写代码的机器。

## 原文 context

全文的转折判断。代码是定义程序与系统的通用语言；harness 说到底是一段规定 prompt、工具调用、子 agent、控制流、记忆与工作流如何协同的代码。Meta-Harness、ADAS、AFlow 等工作说明：一旦 harness 设计变成可执行的搜索空间，强 coding agent 就能利用人类工程师使用的同一片设计空间，且远大于手写 prompt 所能触及的范围。
