# A view is a view

> clip 播放与直播观看在广告计价上等价，一次点亮即一次流量，无高低之分。

> A view is a view. A listen is a listen. An impression is an impression—
这是 clip 经济能够变现的认知前提。传统媒体一直把 clip 当作"次等流量"——觉得 250 万 clip 播放不如 7000 个真实直播观众。但广告主只看一个数字：屏幕被点亮了多少次。一旦承认 clip 流量与传统流量等价，传统媒体那个"巨大的 clip 矿"才能开始变现。
