# 端到端验证

> 只有跑通完整流程才算真正验证，用 e2e pipeline 与 smoke run 补局部测试之不足。

**领域** verification-eval ｜ **类型** CONCEPTUAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.072

## 费曼一下

零件逐个通电正常，不等于装起来的机器能开动。真正的验收是把整台机器打开走一遍全流程，看它有没有从头到尾跑到底。

## 原文 context

L10 的主张「只有跑通完整流程才算真正验证」，在五个子系统里落为 e2e pipeline 与 smoke runs。它是对单元测试式局部验证的补充——局部全绿而整体跑不起来，正是无 harness 组「游戏核心功能跑不起来」的形态。

## 掌握证据（做到这些才算会）

- 能说明为何单元测试全绿仍可能整体跑不起来
- 能设计一条覆盖完整流程的 e2e 或 smoke 检查

## 验收问句

> 为何局部测试全绿还不够，{{name}} 要求跑到哪一步？
