# AI Agent

> 用户感知到的行为体现：Agent 的对外表现，而非其内部实现。

**领域** harness-runtime ｜ **类型** CONCEPTUAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.06

## 费曼一下

AI Agent 是用户看到的“会做事的东西”。它看起来有目标、会用工具、会纠错，但这种行为不是裸模型单独产生的，而是 Harness 把模型组织进执行系统之后的外在表现。

## 原文 context

“用户感知到的行为体现”

## 掌握证据（做到这些才算会）

- 能区分 Agent 的内部实现与用户感知行为
- 能举出一个用户可观察的 Agent 行为
