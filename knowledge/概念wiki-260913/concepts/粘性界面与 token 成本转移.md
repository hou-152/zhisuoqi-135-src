# 粘性界面与 token 成本转移

> 模式洞察：Linear 仍是 SaaS 的粘性界面，是工作发起与信息记录处，却不为 token 付费；成本由模型厂商和 coding agent 承担。

**领域** economy-business ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.042

## 费曼一下

想象一个繁忙的港口。真正烧钱的是跑远洋、烧油的货轮（那是各家大模型和 coding agent 在付 token）；而港口只管调度、收记录、盖章放行，成本低却掌握一切从哪儿开始、往哪儿去。谁守住了“工作从这里发起”的入口，谁就既省了油钱，又拿到了指挥权——这就是上游卡位的杠杆。

## 原文 context

本篇的商业模式核心洞察，也是标题“把上下文变成骨架”的另一面。Dan 点破：Linear 是“这个时代的完美生意”——仍是 SaaS，是工作被发起、信息被记录的粘性界面，却不用为 token 付费，token 成本由 OpenAI、Anthropic 和各家 coding agent 承担。Karri 补充其战略价值在于“坐在工作来源的上游”：bug 与请求一进来就自动 spawn 给 agent，工程师甚至看不到，或看到时已有 fix。

## 掌握证据（做到这些才算会）

- 能说出谁在为 token 付费、谁不必付
- 能解释「坐在工作来源上游」如何让 bug 一进来就 spawn 给 agent
