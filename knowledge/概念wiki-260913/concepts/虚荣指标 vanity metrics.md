# 虚荣指标 · vanity metrics

> 度量产出却不度量价值的指标，如 agent 写了多少代码、合并多少 PR、消耗多少 token。

**领域** agent-org ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.042

## 费曼一下

体重秤上多出的数字，可能是肌肉，也可能是脂肪，还可能是没上厕所。只盯着“产出了多少”，就像只盯着体重秤——数字在动，却说不清你到底变好还是变差。虚荣指标让人感觉良好、便于汇报，但真正该问的是那个不好看的、滞后的问题：产品真的更好了吗？

## 原文 context

Karri 常在 Twitter 上调侃的对象——“如今最大的虚荣指标是你多少代码是 agent 写的、你合并了多少 PR”。这类指标度量产出，却不度量价值：产品是否改进、是否解决了用户问题。他主张用滞后但真实的指标（利润、营收、用户喜爱）以及可度量的 bug 数作为反平衡，而不是把 token 使用量推成唯一指标。

## 掌握证据（做到这些才算会）

- 能举出至少两个虚荣指标并说明它不反映价值
- 能为每个虚荣指标配一个滞后但真实的替代指标
