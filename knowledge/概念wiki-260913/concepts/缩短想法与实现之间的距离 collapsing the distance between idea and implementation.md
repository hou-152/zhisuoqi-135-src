# 缩短想法与实现之间的距离 · collapsing the distance between idea and implementation

> 把 agent 植根于产品与代码库的完整上下文，压缩想法到实现的距离。

**领域** code-engineering ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.017

## 费曼一下

传统上，从"我有个点子"到"它真的上线了"要经过漫长的传递、排期、返工。当 agent 手握全部上下文、能直接把想法往下推，这段路被大幅缩短——想到和做到之间的鸿沟越来越窄，几乎可以一步跨过去。
