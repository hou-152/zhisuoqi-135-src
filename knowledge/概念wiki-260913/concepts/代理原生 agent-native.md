# 代理原生 · agent-native

> 不给旧产品外挂 chatbot，而是把产品从底层做成供 agent 使用、并为其提供上下文与集成的形态。

**领域** agent-org ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.117

## 费曼一下

普通软件是给人用的，界面、按钮、说明都围着人转。agent-native 软件是给 AI 用的——它默认读者是一个 agent，于是把“该带什么上下文、能调哪些能力、怎么完成任务”都摆好。就像同一栋楼，一种是为行人设计的商场，另一种是为无人车设计的仓库：后者的通道、标识、货架都按机器的读取方式重排过。

## 原文 context

文中反复出现的核心定位词。Linear 被描述为“成功转型为 agent-native”的少数公司之一——不是给旧产品外挂一个 chatbot，而是把产品从底层改造成“供 agent 使用、并为 agent 提供上下文与集成”的形态。它的 agent 平台文档很好，agent 能自己读文档、自建集成，因此大多数 coding agent（含 OpenAI 的 codex）都接了进来。

## 掌握证据（做到这些才算会）

- 能说明 agent 能否自己读文档、自建集成是判别标准
- 能举出 coding agent 因此主动接入的例子
