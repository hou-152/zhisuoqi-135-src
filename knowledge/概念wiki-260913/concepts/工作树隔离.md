# 工作树隔离

> 为每个并发 Agent 分配独立工作空间，避免改同一文件造成冲突，便于事后合并。

**领域** multi-agent ｜ **类型** PROCEDURAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能用 ｜ **中心度** 0.035

## 费曼一下

让每个 AI 在自己的小房间里改代码，改完再拿出来合并。否则大家挤在一张桌子上改同一份文件，很容易互相踩坏。

## 原文 context

当多个 Agent 同时工作时，作者强调要给每个 Agent 一个独立工作空间，避免互相改同一个文件造成冲突。这个组件支撑并发执行和事后合并。

## 掌握证据（做到这些才算会）

- 能同时启动多个 Agent 且文件不互相覆盖
- 能说明隔离与合并之间的先后顺序
