# 基准测试的捆绑测量性

> 基准很少单独测量模型，它同时测了 API 设置、harness 设计与提示词等不可见选择。

**领域** verification-eval ｜ **类型** CONCEPTUAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.089

## 费曼一下

你以为分数是模型的体检报告，其实它是模型加上一整套工程默认值的联考成绩。想从分数里读出模型能力，必须先知道监考规则；否则你比较的可能只是两套脚手架。

## 原文 context

全文的主命题，开头和结尾各说一次：「Benchmarks rarely measure AI models in isolation. They also measure less visible choices about API settings, harness design, and prompting.」

## 掌握证据（做到这些才算会）

- 能指出某次跑分里除模型以外的变量
- 能设计一个区分模型能力与 harness 贡献的对照
