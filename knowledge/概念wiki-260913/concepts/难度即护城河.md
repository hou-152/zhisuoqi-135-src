# 难度即护城河

> 真实应用的痛点源自基底本性、无法被工程掉，只能由 harness 吸收；难做与难被复制同源，即护城河。

## 原文 context

全文收束。所有痛点都是结构性地难，源自基底本性而非工具不成熟；这些事实无法被工程掉，只能被一个 harness 吸收。而这正是护城河：如果 harness 工程很容易，模型就是产品，任何有 API key 的人都能竞争；真实应用之所以难做与难被复制，是同一个原因。「The pain is the work, and the work is the moat.」

## 掌握证据（做到这些才算会）

- 能区分哪些痛点是结构性的、哪些只是工具不成熟
- 能说明为何 harness 工程易做时模型就变成产品
