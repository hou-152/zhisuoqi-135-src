# Software for one

> 不必做给百万人的 App，可以只做给一个人用的软件，满足个体独有需求。

**领域** economy-business ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.045

## 费曼一下

把「产品」的尺度从一百万人砍到一个人。降低了立项的心理成本，也让产品和业务同学拥有了天然优势——你最懂自己每天的麻烦在哪。

## 原文 context

> 《纽约时报》专栏作家 Kevin Roose 提过一个概念叫 software for one：你不需要做给一百万人用的 App，可以做只给你一个人用的软件。

## 掌握证据（做到这些才算会）

- 能举出一个只为自己用的软件并说明需求来源
- 能判断某需求该做通用产品还是自用一次性工具
