# 产品记忆平台 · product memory platform

> 把产品定位为“产品上下文／产品记忆”的所在地，而非通用 agent 平台，是通往产品思考的 API。

**领域** agent-org ｜ **类型** REPRESENTATIONAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.045

## 费曼一下

通用 agent 像一个每天失忆的临时工，你每次都得从头交代背景。产品记忆平台像一个跟了你多年的老同事，你只说半句，他就知道你指的是哪个项目、上次卡在哪、客户要什么。价值不在“更聪明的大脑”，而在“共享且长期沉淀的记忆”——上下文本就活在那里，不必每次重新搬运。

## 原文 context

Karri 给 Linear 的定位，用来和“通用 agent 平台”划清界限。Linear 不追求让你在上面跑随便什么东西，而是做“产品上下文 / 产品记忆”的所在地——它是围绕产品工作的方式、是一个通往“产品思考”的 API。相比之下，用 Claude、ChatGPT 或 codex 时，你每次都得显式告诉它带什么上下文，因为它不知道你一般在做什么。

## 掌握证据（做到这些才算会）

- 能用一句话区分产品记忆平台与通用 agent 平台
- 能说明为何用通用模型时每次都要显式交代上下文
