# 编码 agent / 智能体 · coding agent / Agent

## 费曼一下

本文里的编码 agent 不是被动补全代码的工具，而是能接收自然语言目标、选择搜索工具、读取代码并返回线索的执行者。后面的 grep、语义搜索、Explore 子代理、架构图和“修改前先探索”都围绕它展开。
