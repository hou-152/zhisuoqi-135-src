# 共享产品系统 · shared product system

> 承载反馈、意图、决策、计划与代码的载体，让人与 agent 能共同在其中工作。

**领域** agent-org ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.126

## 费曼一下

不是给人一个系统、给 agent 另一个系统，而是让两者共用同一个工作台。人在上面提需求、拍决策，agent 在同一处读取这些信息、接着往下做。共享的意思是：同一份上下文，人和机器都看得见、都能动手。

## 原文 context

承载上下文的载体，也是 Linear 的自我定位内核——一个"人与 agent 能共同工作的系统（a system that humans and agents can work from together）"。它同时容纳反馈、意图、决策、计划与代码。
