# 设计文档

> 文档是人与 Agent、Agent 与 Agent 之间的桥梁，也是记忆载体。

## 费曼一下

传统文档可能是写完就过时的负担；本文里文档是核心中间物。人靠它确认和修改方案，Agent Session 靠它继承前一个 Session 的决策和上下文。没有它，人无法高效确认，Agent 也无法跨阶段接力。

## 原文 context

文档在 AI 时代有了全新的角色，它是人和 Agent 之间、以及 Agent 和 Agent 之间的桥梁。

> 换句话说，文档是 AI 原生开发中的“记忆载体”。

> 确认后的文档，就是下一个 Agent Session 的全部起点。
