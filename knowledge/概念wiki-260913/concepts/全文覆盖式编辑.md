# 全文覆盖式编辑

> 大改动时不用增量 Edit，直接 Write 覆盖整个文件，以绕过精确打补丁的困难。

**领域** code-engineering ｜ **类型** PROCEDURAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能用 ｜ **中心度** 0.017

## 费曼一下

与其教模型精确地做外科手术，不如让它把整份文件重抄一遍。笨、贵，但可靠得多——很多工程难题的最优解就是用算力换掉一个必须训练的模型。

## 原文 context

作者发现 claude code 的 tool call 基本只用 Write 而不用 Edit，Edit 的 spec 里明写「For larger edits, use the Write tool to overwrite files」。他的顿悟是：直接无脑全文覆盖，就绕过了 apply edit 的困难，「只是费电 token 罢了」。

## 掌握证据（做到这些才算会）

- 能说明 Edit 规格中「大改动请用 Write 覆盖」的建议
- 能权衡覆盖写法多耗 token 与正确率之间的取舍
