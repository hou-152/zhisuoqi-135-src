# 记忆冲刷（Memory Flush）

> 压缩前向模型下达保存指令，优先留存用户偏好、修正建议与重复模式而非任务细节。

> 在压缩之前，它会发送一条指令告诉模型：「会话即将压缩，请保存任何值得记住的东西。优先保存用户偏好、修正建议和重复模式，而非具体的任务细节。」
