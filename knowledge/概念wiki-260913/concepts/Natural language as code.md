## 原文 context

Natural language as code 指自然语言不再只是说明文字，而是会驱动 agent 行为的可执行逻辑。

## 掌握证据（做到这些才算会）

- 能把一句说明改写成会改变 agent 行为的指令
- 能判断某段自然语言是否真的会被执行

## 验收问句

> 你这段自然语言会真的改变 {{name}} 的行为吗？
