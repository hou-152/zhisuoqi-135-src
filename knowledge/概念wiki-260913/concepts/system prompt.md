# system prompt

> Agent 启动时由 harness 注入、用户不可见的开场提示，用来设定角色、规则与可用工具。

**领域** context-engineering ｜ **类型** CONCEPTUAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能用 ｜ **中心度** 0.017

## 费曼一下

system prompt 是 agent 的隐形操作手册，规定它的角色、权限、工具格式、协作方式和安全边界。

## 原文 context

coding agent 会以用户不可见的系统提示开场。

## 掌握证据（做到这些才算会）

- 能指出自己所用 coding agent 的系统提示在会话中不可见
- 能写出并注入一段系统提示，并说明它与其他消息的优先级
