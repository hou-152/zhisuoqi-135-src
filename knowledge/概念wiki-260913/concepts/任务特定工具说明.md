# 任务特定工具说明

> 相同工具必须按产品工作边界配置 instructions，code review 式聚焦说明在 CLI 中无同等收益。

**领域** tools-sandbox ｜ **类型** PROCEDURAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能用 ｜ **中心度** 0.045

## 费曼一下

同一张地图，导游、快递员和消防员的使用方式不同。说明书要告诉 agent 它现在扮演什么角色，而不只是地图上有什么。

## 原文 context

code review 的聚焦说明在 CLI 中没有同等收益，因为 CLI 的任务更开放、可多轮转向。相同工具必须按产品工作边界配置 instructions。

## 掌握证据（做到这些才算会）

- 能对比 CLI 与 code review 场景下同一工具的指令差异
- 能为一个工具写出匹配其工作边界的说明
