# 并不 agentic」的 AI Agent

> 以 AI Agents 为卖点的产品多数并不 agentic，主要是确定性代码，只在恰到好处的点上撒入 LLM 步骤。

**领域** agent-org ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.045

## 费曼一下

好的自动驾驶不是让方向盘随机发挥，而是把绝大部分路况交给确定的规则，只在少数需要判断的时刻调用智能。agent 也一样：LLM 是点睛，不是骨架。当你发现产品做得好的地方其实是普通代码在支撑，那不是失败，那正是它能上线的原因。

## 原文 context

作者的惊讶发现——市面上以 "AI Agents" 为卖点的产品「are not all that agentic」，多数是 mostly deterministic code，只在恰到好处的点上撒进 LLM 步骤，体验才 truly magical。

## 掌握证据（做到这些才算会）

- 能拆解一个 Agent 产品里哪些是确定性代码、哪些是 LLM 调用
- 能说明这种结构为何体验反而稳定神奇
