# 自协调与共享协调文件

> 最早的多 agent 方案：平等角色的 agent 用共享状态文件看别人在做什么、决定自己做什么并更新文件，最少规定，结果很快失败。

**领域** multi-agent ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 只能认 ｜ **中心度** 0.126

## 费曼一下

让一群地位相同的人共用一块白板，各自写下"我在干什么"，指望他们自己把活分好。听上去很民主，实际是每个人都在抢那支笔，而且没人愿意认领最难的活。

## 原文 context

第一个多 agent 方案——"have agents with equal roles use a shared state file to see what others are working on, decide what to work on, and update the file"，设计哲学是"be the least prescriptive"。结果 "This failed quickly."

## 掌握证据（做到这些才算会）

- 能复述该方案的规则与其“很快失败”的结论
- 能说出最少规定的设计为何失效
