# 仓库技能的跨模型影响

> 仓库技能会被其他贡献者、可能不同模型的 agent 读取，帮某模型的措辞可能过度约束另一个。

**领域** spec-intent ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.072

## 费曼一下

仓库技能会传给其他贡献者的代理，它们可能用不同模型。帮 Sol 或 Luna 的指导可能给 Astra 过度约束。写指令时得考虑最终有哪些模型会读，这是多模型共用同一套技能时的边界。

## 原文 context

Repository skills also guide other contributors’ agents, which may use different models. Guidance that helps Sol or Luna may overconstrain GPT-6 Astra, so consider which models will use the instructions you leave behind.

## 掌握证据（做到这些才算会）

- 能说出仓库技能会传给使用不同模型的 agent
- 能判断某句指导对别的模型是否构成过度约束
