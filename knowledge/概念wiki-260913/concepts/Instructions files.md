# Instructions files

> 给 AI agent 写的长期工作规则文件（如 AGENTS.md/CLAUDE.md），每次执行任务都直接影响模型行为。

## 原文 context

Instructions files 是 AI agent 的长期工作规则。它们类似项目里的 README、lint 规则和团队约定，但直接影响模型每次执行任务时的行为。
