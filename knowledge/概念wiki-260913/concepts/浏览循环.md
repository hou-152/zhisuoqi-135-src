# 浏览循环

> review agent 广泛搜索、猜路径、大量读码，再从新内容发起更多搜索的行为模式。

**领域** verification-eval ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.042

## 费曼一下

每次搜索都发现一点新东西，于是 agent 永远觉得还该再看一点。它一直在移动，却没有更接近要回答的问题。

## 原文 context

review agent 广泛搜索、猜路径、读取大量代码，再从新内容发起更多搜索，表现得像在理解整个仓库而不是验证 diff 风险。

## 掌握证据（做到这些才算会）

- 能描述搜索—读取—再搜索的自我扩张循环
- 能说明它像在理解整个仓库而非验证 diff 风险
