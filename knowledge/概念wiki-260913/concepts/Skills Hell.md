# Skills Hell

> skill 数量膨胀、互相冲突或长期不维护，像 framework hell 一样拖低 Agent 可靠性。

**领域** context-engineering ｜ **类型** CONCEPTUAL ｜ **什么时候学** 做到这里再懂 ｜ **怎么算会了** 能判 ｜ **中心度** 0.236

## 费曼一下

手册太多、太长、互相矛盾时，员工反而不知道该听谁的。更少、更小且结构清楚的规则更有效。

## 原文 context

Skill 数量膨胀、结构混乱、相互冲突或长期不维护，会像 framework hell 一样降低 Agent 可靠性。

## 掌握证据（做到这些才算会）

- 能指出自己 skill 库里重复或冲突的两条
- 能给出合并或下架 skill 的清理方案
