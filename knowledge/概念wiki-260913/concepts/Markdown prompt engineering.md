# Markdown prompt engineering

> 用清晰的 Markdown 层级区分背景、任务、约束与验证标准，而不是把 prompt 写得更华丽。

**领域** context-engineering ｜ **类型** PROCEDURAL ｜ **什么时候学** 现在先懂 ｜ **怎么算会了** 能用 ｜ **中心度** 0.017

## 原文 context

Markdown prompt engineering 不是把 prompt 写得更华丽，而是用清晰层级告诉模型：什么是背景，什么是任务，什么是约束，什么是验证标准。

## 掌握证据（做到这些才算会）

- 能写出一份分层 prompt 并标出四类信息
- 能指出一份 prompt 中背景与任务混淆的具体句子

## 验收问句

> 你能按 {{name}} 把混乱 prompt 重排成背景/任务/约束/验证四层吗？
