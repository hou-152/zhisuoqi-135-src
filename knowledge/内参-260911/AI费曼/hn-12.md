文章在回答：当 Claude 越来越强、任务越跑越长，自己搭的“挽具”（harness）反而会拖后腿，怎么办？Anthropic 的答案是不赌某一种挽具，而是把大脑（模型加挽具）、双手（沙箱和工具）、日记（会话日志）拆成三个接口，各自能独立坏、独立换，并把整套挽具和基础设施托管掉。核心机制是：直连模型的 API 只负责一问一答，你得自己补挽具；挽具里写满了“模型做不到什么”的假设，模型一进步这些假设就过时；同时任务时长指数变长，压力从模型转向基础设施。于是托管让你只填配置，沙箱和执行记录都由平台管。类比：过去你租发动机，车架和车库自己搭；现在连车架和车库一起租，只填“这台车怎么配”。作者承认的边界是：托管解决了挽具和基础设施，但“把什么任务交给 agent、多个 agent 怎么编排”这些上层判断仍留给开发者。
