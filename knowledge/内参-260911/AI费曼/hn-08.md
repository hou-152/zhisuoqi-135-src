这篇文章在回答：构建 AI agent 应用，框架该给多少抽象才合适？OpenAI 的答案是尽量少，只保留三个原语——Agent（模型+指令+工具）、Handoff（把任务交给别的 agent）、Guardrail（并行校验输入输出），其余编排逻辑直接用 Python 写。就像工具箱只给你三种基础零件，但零件能自由拼装，因为你用的是本来就会的螺丝刀，而不是专用工具。它内置的 agent loop 替你自动转“调工具—拿结果—喂回模型—判断结束”这个来回，省得自己写循环。作者也承认边界：如果你的工作流只是想拿模型一次响应、自己掌控循环和状态，那直接调 Responses API 更合适，不必非用 SDK；同一个项目里可以按路径混用两种方式。
