## 费曼一下
AWS 的 **Agent 原语库**——记忆、安全执行、权限等单独的零件，开放给所有人自己拼 Agent 工作流。
和 Bedrock Managed Agents 的关系是 **原语 vs. 成品**：
- AgentCore 像乐高积木，谁来都能拼，OpenAI/Anthropic/自家模型都能接；
- Managed Agents 是 AWS × OpenAI 在 AgentCore 上面做出来的「成品 Agent 平台」，OpenAI 模型 native 进 Bedrock，且 AWS 独家。
这套「原语 + 成品」分层，是 AWS 经典的平台打法——一层做开放生态、一层做联合精品，别人复制起来又难又慢。
