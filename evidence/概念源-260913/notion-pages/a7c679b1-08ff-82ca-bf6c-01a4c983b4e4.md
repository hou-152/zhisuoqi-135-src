## context
> A resolver is a routing table for context. When task type X appears, load document Y first.
>
> Skills tell the model how. Resolvers tell it what to load and when.
作者忏悔：自己的 `CLAUDE.md` 曾写到 20,000 行，模型注意力退化，**Claude Code 亲自劝他砍**；修完只剩约 200 行纯指针，20,000 行知识仍在但按需加载，不污染 context。
## 费曼一下
resolver 是「何时加载哪份文档 / 哪个能力」的路由器。
- skill 告诉模型 **how**（怎么做一件事）；
- resolver 告诉模型 **what to load and when**（什么时候该加载什么到上下文里）。
Claude Code 里每个 skill 的 `description` 字段就是天然的 resolver——模型按用户意图自动匹配。开发者不需要记得 `/ship` 存在，description 就是路由。
**价值：**让 20,000 行领域知识可以躺在 docs 里，由 resolver 在对的时刻把对的那份拼进 context window，而不是全部堆在 system prompt 里让注意力被稀释。
它与 skill、harness 的关系：
- skills 是**能力库**；
- resolver 是**能力派单**；
- harness 是**跑那些能力的 runtime**。
三者一体，才能让一个 agent 在不肨胀 context window 的前提下拥有海量领域知识。
