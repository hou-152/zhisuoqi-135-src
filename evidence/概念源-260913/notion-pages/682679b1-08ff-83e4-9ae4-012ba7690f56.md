## context
> "the ability to go authenticate to your database all happens inside of your AWS VPC ... data is protected inside of the Bedrock environment."
## 费曼一下
客户在 AWS 上**自己的私有网络隔离区**——20 年前 AWS 就攒下来的安全原语。
在 Managed Agents 时代，VPC 突然变得极其关键：它是 OpenAI 模型 + AWS 运行时跑进客户内部的**安全边界**。核心承诺：
- Agent 的运行 → 在 VPC 里；
- 对内部数据库的认证 → 在 VPC 里；
- 客户数据 → 在 VPC 里；
- OpenAI **不直接看见**。
这是企业「我喜欢这能力但怎么避免一次公司级事故？」这个焦虑的标准答案——**用云的安全工具去框住 Agent**，而不是用本地隔离假装安全。
