> A sensor turns some state of the world into digital information. An actuator lets an agent change something. The future stack is agents using sensors and actuators on behalf of people and organizations.
**费曼一下**：agent-native 世界的两个原语。
- **sensor**（感知器）：把现实世界状态数字化，让 agent 能"看见"
- **actuator**（执行器）：让 agent 能在世界里采取动作
借自机器人学，Karpathy 用它来描述新软件栈的两个最小单位：整个互联网/产品基础设施会被重构成 **"agent 通过 sensor 感知世界、通过 actuator 改变世界，代表人和组织行动"**。
这是 **Agent-Native Infrastructure** 的底层抽象：所有 API、CLI、MCP server、structured logs、permission system，本质上都是某种 sensor 或 actuator。
