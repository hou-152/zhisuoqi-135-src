## context
> 与其等 AI 去各个站点零散地抓信息，不如给它一个集中的入口，把你希望它记住的东西整理好放在那里。
## 费曼一下
作者自创的概念，对应他的 Yobi 项目（名字来自日语 “呼び / よび”，有呼唤、把人叫过来的动作感）。一个专门为 AI 准备的“中央知识枢纽” —— 把概要、完整版、独立项目页、JSON API 都放在一个站点。AI 来了不用东拼西凑，一站获取完整结构化信息。
## 三件东西
1. 精简版的 `llms.txt` 概览
2. 完整版的 `llms-full.txt`，约 50KB，把所有项目的描述、FAQ、使用场景、竞品对比、README 摘录都放进去了
3. 每个核心项目的独立知识页面（`/projects/pake`、`/projects/kaku` 等）以及 JSON API（实时拉 GitHub stars/forks/release）
