## context
> 我并不认为用户界面（UI）正在死亡。人类仍然想要点击按钮、查看配置、确认任务已经完成。但二八法则已经反过来了：未来人与软件之间 80% 的交互，都会通过 AI 智能体完成。
## 费曼一下
- 过去 80% 是人点界面、20% 走 API；未来 80% 是 Agent 走 API/MCP、20% 是人在 UI 上确认。
- UI 不会死，但**主从关系翻转**——产品的精力分配也要随之倒过来：先把能力做成可被 Agent 调用，再补 UI 上的人类确认环节。
- 直接信号：Ramp 三个月 MCP 周活 10 倍增长；Salesforce 推出 Headless 360。这些不是细节优化，是大盘转向的早期前置数据。
## 与本文其他概念的关系
- 二八反转是**起因**：是它倒逼 Headless 架构、A2A 交互、以及为 Agent 设计产品的三条原则。
- 配套问题：一旦 80% 的调用走 Agent，原本走 UI 才看到的"用户在干什么"信号会消失，产生**可观测性**与**上下文缺口**两类新问题。
