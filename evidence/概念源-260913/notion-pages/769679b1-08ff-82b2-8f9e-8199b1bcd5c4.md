## 费曼一下
OpenAI 的代码 Agent 产品，本文里被反复当作 **「Agent 应该长什么样」的活样板**。
Codex「好用」的原因有两层：
- 表层是 model + harness 集成度极高——Sam 自己都分不清惊艳输出是模型功劳还是 harness 功劳；
- 底层是**本地运行**——环境、数据、安全都默认到位，复杂性被「自我施加的城堡」屏蔽掉了。
但 Sam 自己说：终局应该是**云端**——本地的「免费安全」是过渡红利，多 Agent、多人协作、权限边界都会逼着 Codex 这类产品最终长在云上。Bedrock Managed Agents 就是「云端版 Codex」要落的地。
