## 费曼一下
Bedrock Managed Agents 的内部系统名——**有状态的 Agent 运行时**。
两个关键词：
- **Runtime**：Agent 的执行环境，不是单次 API 调用；
- **Stateful**：跨调用记得东西、能持续做长任务、能跨会话维持记忆和上下文。
SRE 的设计目标是：让客户**完全感受不到底下跑什么芯片、用什么模型**——你只看见「有一个能记事、能干活的 Agent 在我 VPC 里跑」。
它解决的是 Agent 时代的「装机难度」问题——以前每家公司都要自己粘记忆、状态、调度、权限；现在这一层被 AWS 直接做成 runtime，像 EC2 之于服务器、Lambda 之于函数。
