## context
> "you have the old school security model, which is like the castle-and-moat sort of thing, and you're moving to a new security model of zero trust ... running locally, it's like your self-imposed castle-and-moat ..."
## 费曼一下
Ben 用来切「Local Agent vs. Cloud Agent」的安全心智模型——
- **城堡 + 护城河**：默认环境内可信，省掉一堆权限/认证。Codex 跑在本地就是这种**自封的城堡**——很多复杂性「天然解决」其实是被本地边界屏蔽了。
- **零信任**：每个动作都要带身份、带权限，不预设任何「可信区域」。
Agent 时代必须走零信任，原因很硬：
- 多 Agent、多人、多权限边界，城堡心智根本撑不住；
- 一个员工 + 一个 Agent + 还有别的 Agent 的组合，需要细到「Agent 用了谁的身份做了什么」的审计；
- Bedrock Managed Agents 的整套（VPC + Gateway + Role）就是把 AWS 20 年的零信任工具，**第一次完整对准 Agent 这个新存在**。
本地的「免费安全」是过渡红利，零信任才是终局基建。
