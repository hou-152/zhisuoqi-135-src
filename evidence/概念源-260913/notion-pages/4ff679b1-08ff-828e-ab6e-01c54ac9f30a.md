## context
> 把平台里的每一项能力都暴露成 API、MCP 工具或 CLI 命令，让 AI 智能体可以在完全不打开浏览器的情况下操作整个系统。这是 Salesforce 在过去 27 年里最激进的一次架构转型。
## 费曼一下
- "砍掉头"——把界面从产品里剥离，留下纯能力层。
- 历史含义：Headless CMS 是把内容层与展示层解耦；Salesforce 的 "Headless 360" 把这一思路推到 SaaS 全栈，把整套 CRM 都做成可被 Agent 直接调用的能力库。
- 行业含义：Salesforce 自己把"统一一致的 UX 是护城河"这条护城河承认掉一半——因为未来大量行为根本不会经过浏览器。一个 SaaS 公司是否 "Headless-ready" 正在成为新的硬指标。
## 与本文其他概念的关系
- 是**二八反转**的架构落地：要让 80% 的交互走 Agent，必须先把界面里的能力剥到外面。
- 是**A2A 交互**的物质基础：用户 Agent 与软件 Agent 协作，必须有可被双方调用的能力面。
- 是"为 Agent 设计产品"三原则的施工现场——三原则讨论的就是 Headless 暴露后的工具/参数/反馈该怎么打磨。
