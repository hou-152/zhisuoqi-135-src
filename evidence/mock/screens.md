# 5 屏 × 数据 × mock 对照（前端开工用）

> 对着 `docs/前端契约-知所栖135.md` §四 看。**每屏吃什么、用 mock 里哪一条、三个状态反馈怎么做**，全在这一页。
> 判定的口径不在前端 —— 前端只显示结果（契约 §〇）。

## 形态一句话（先看这个，它决定 5 屏长什么样）

**不是「看完一篇文章」，是一次一题、答完立刻判、每题都能点回原文。**
多邻国式的节奏，知乎的内容做底。五个屏是**读 → 判 → 做 → 讲**一条链，不是五个功能页。
**每个判定都必须给出处，出处必须点得回去** —— 这是它和 Duolingo 的区别，也是它和知乎的关系。

## 五个屏

| # | 屏 | 吃什么 | mock 里用哪条 | 关键约束 |
|---|---|---|---|---|
| 0 | 入口 / 概念图 | 壳 payload：`nodes[936]` `edges[531]` `curation.tags[21]` `kinds.dist` | `fixtures.payloadSample` | 完整数据已内联在 `prototype/知所栖-壳.html` 的 `const DATA`，**不要复制第二份** |
| 1 | 1 阅读 | `POST /api/llm` `{skill:'dbs-learning', json:false}` → `content` | `POST /api/llm · 1 阅读（skill=dbs-learning）` | 三层梯度 L1 直觉 / L2 机制 / L3 应用，**可切**；一次只给 3 个概念，给完就停 |
| 2 | 3 决策 | 五语义 `CAS-*`（决策场） | `fixtures.unitsSample.CAS` | **先让学习者自己选，再揭晓**。顺序反了这屏就没意义 |
| 3 | 5 实验 | 五语义 `SOL-*`（方案 → 实验台） | `fixtures.unitsSample.SOL` | 5 次提取练习，每次显示「做什么 / 看什么 / 得出什么」；**必须让他动手判断** |
| 4 | 费曼验收 | `POST /api/search` ×3（证据）+ `POST /api/llm`（判定 JSON） | `POST /api/search`、`费曼判定（过）`、`费曼判定（有漏点）` | 判定回包 `{result:{<概念id>:{pass,covered:[下标]}}}`；`covered` 是**要点下标**，自己去 `node.evidence[]` 取标签 |

## 状态反馈（契约 §四 写死的三条 —— 不做就是没做完）

| 状态 | 怎么表现 | mock 里拿什么试 |
|---|---|---|
| **加载** | 每次 LLM 调用都要有进度文案（参考：`检索知乎证据 1/3…` → `AI 检验中…`），并且**要能超时降级**（现原型是 30s 后落规则判定） | 任意 llm 样本 |
| **失败** | `/api/llm` 返回 `{error}` 时不许白屏，要降级并**明说降级了** | `POST /api/llm · 失败态` |
| **空态** | 该概念没有真实案例 / 没有实验 → **明说没有**，不许编一条 | 把 `unitsSample.CAS` 改成 `[]` 自己试 |
| **跳过 ≠ 未通过** | 跳过记「未验收」，只有判定失败才记「未通过」 | `费曼判定（有漏点）` |
| **限速器** | 三个模块走完但没复述 → 首页显示「**本次尚未验收**」 | 不调第 4 屏，直接回首页 |
| **只能认的不设验收** | `node.k === 'accept'` 的世界观类概念**不设验收**，只记「读过」 | 挑一个 `k:'accept'` 的点 |

## 连 mock 跑（不用 serve、不用 key）

```html
<!-- 在业务脚本之前加这一行；接真接口时删掉即可，业务代码一行不改 -->
<script src="evidence/mock/mock-fetch.js"></script>
```

改完跑 `node scripts/verify-mock.mjs` —— mock 的键和真实代码读的键对不上时它会红。

## 两个必须知道的边界

1. **5 屏现在住在哪**：`prototype/知所栖-135-基础框架.html`（手改源文件，**不是**构建产物）。
   而 `prototype/知所栖-壳.html` 与 `prototype/知所栖-135-公网版.html` 是构建产物，手改会被覆盖。
   两者**零共享代码** —— 把 5 屏做进壳里，是这轮的实际工作量，不是「改改样式」。
2. **公网版只烘了壳**：`build-public.mjs` 的输入是壳，所以主线现在**不在公网 Demo 里**（线上 0 处「本次尚未验收」）。
   这不是前端的问题，但**演示当天只开公网链接就会看不到主线** —— 记在心上。
