## 6. 短答承接、错题回补、章末门与暂停恢复结果

| 要看到的 | 结果 |
|---|---|
| 只补一句能承接旧证据 | 新回答没重述旧判据 → **保留旧证据**、不新增 `missing`，并留一条 `kept` 记录 |
| 新矛盾触发相关核对 | 明确推翻旧关系 → 记 `conflictAt` + 保留 `previous` + 进补讲重新核对 |
| 补讲结束回原活动 | 三条真路径都验过：从阅读中费曼发起 → 回阅读中费曼；从某道题发起 → **回那一道题**；从章末发起 → **回章末** |

| 即时费曼不解锁 | 讲对了也不写正式通过、也没有"跳下一单元"这条边 |
| 章末门独立 | 通过必须来自**一次独立的章末验收记录**（逐条判定全 met）；补讲 `met` 之后仍然没过 |

| 系统异常不记成缺口 | 超时 / 非法 JSON / 未知 ID / 非法状态 → 进"系统未判定"，草稿与旧证据不动，既不通过也不算学生不会 |
