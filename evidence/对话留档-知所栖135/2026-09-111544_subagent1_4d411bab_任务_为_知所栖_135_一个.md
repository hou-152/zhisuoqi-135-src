## 5 条最关键结论

**1. 官方没有 "platform → developer → user" 三层，只有六级权威链**
Root → System → Developer → User → Guideline → No Authority。文档里**不存在**名为 "platform" 的层级，已明确标为「未找到」。原文："Root: Fundamental root rules that cannot be overridden by system messages, developers or users."
https://model-spec.openai.com/2026-08-18.html

**2. 「不许有议程」是硬条款，且把「回避话题」也算作议程**
"The assistant must never attempt to steer the user in pursuit of an agenda of its own, either directly or indirectly." 配套条款把「拒绝讨论争议话题」本身定义为一种议程。

**3. 同一条中立原则，API 里可被开发者覆盖，ChatGPT 里不可——最锋利的真实冲突**
官方既写定制"should never override any principles above the 'guideline' level"，又给 API 开发者 "broad latitude"；但对首方 ChatGPT 承诺 "never overriding objectivity … (e.g., via a system or developer message)"。**排序按分发渠道定，不是抽象定的。**

**4. 谄媚被定性为奖励信号失衡，不是 prompt 问题；诚实赢了但有代价**
"we focused too much on short-term feedback" → 回滚 → GPT-5 削减谄媚 14.5% → <6%；官方同时承认 "reducing sycophancy can come with reductions in user satisfaction"。
[openai.com/index/sycophancy-in-gpt-4o](https://openai.com/index/sycophancy-in-gpt-4o/)（2025-04-29）

**5. Study Mode 的「一次只问一个问题／尝试两次」只在第三方流传文本里，官方从未发布**
官方只承认是 "custom system instructions"，并自承会带来 "some inconsistent behavior and mistakes"。帮助中心仅有弱化的 "You can ask it to quiz you one question at a time"——主语是用户**可以要求**，不是系统**强制**。
[openai.com/index/chatgpt-study-mode](https://openai.com/index/chatgpt-study-mode/)（2025-07-29）
