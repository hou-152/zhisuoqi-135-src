## 2. 本次目标

把壳的信息层级从「六个入口挤在左栏、936 条概念常驻中间栏」重排成**三级下钻**：

**一级导航 → 二级主题 → 三级概念**

让第一次打开的人在无人讲解下，60 秒内走到「某条主题下的某个概念」。

## 3. 用户与关键场景

### 场景 1｜第一次打开的人（评委 / 队友，无人讲解）
- **用户**：拿到链接，没有任何上下文，不知道这个网站是干什么的
- **旅程**：打开 → 左栏看到 `内参` `知识体系` → 点「知识体系」→ 中间栏出现 21 条主题 →
  点「上下文工程」→ 中间栏换成该主题下的概念、画布只亮这一列 → 点一个概念 → 右侧出详情
- **结果**：知道这是什么、自己下一步能点哪；不需要有人在旁边讲

### 场景 2｜读内参的人
- **用户**：想读当期 AI 内参的人（内参是产品的输入源，也是独立的一栏内容）
- **旅程**：点 `内参` → 中间栏 10 篇 → 点一篇 → 主区阅读页（三级笔记 / 概念网络 / 费曼 ×3 / 阅读原文）
  → 点概念卡 → 跳回知识体系那张卡
- **结果**：从「读到一段话」到「看到它在知识体系里的位置」——内参不是孤岛

### 场景 3｜被倒逼的学习者
- **用户**：想确认自己真懂某个概念的人
- **旅程**：打开一个概念 → 右侧面板写下自己的复述 → 交卷 → 系统挑漏（漏点 / 说错）→ 漏点倒回前置概念
- **结果**：拿到「自己哪里没懂」，而不是一个「已学习」的绿勾

## 4. 页面结构

壳是**单文件、单页面**。层级靠**栏内下钻**表达，不新增路由、不做多页：

```
/  壳
   ├── 左栏      一级导航（内参 / 知识体系）+ 搜索
   ├── 中间栏    二级（主题）↔ 三级（概念），两态互斥
   ├── 主区      知识体系 → 画布；内参 → 阅读页
   └── 右侧面板  概念详情 + 倒逼输入
```

## 5. 信息架构

### L1 · 左栏（一级）

- **品牌 + 搜索框** —— 「筛选」是页面级的入口，留在一级（Linear 风格：搜索在上、导航在下）
  - 内容槽：搜索输入框 ×1（占位文案要说明它筛什么）
- **一级导航** —— 两个入口，**顺序：内参 → 知识体系**（内参在上）
  - 内容槽：`内参`（+ 期数/篇数）/ `知识体系`（+ 概念数）

### L2 · 中间栏，默认态 = 主题

- **主题列表** —— 21 条主题，点一条进入该主题（下钻到 L3）
  - 内容槽：主题名 / 该主题下的概念数 / 颜色标识
  - **这 21 条从 L1 左栏搬到这里**——「主题是二级」

### L3 · 中间栏，点主题后 = 概念

- **面包屑** —— 「← 全部主题」，回到 L2
- **该主题下的概念列表** —— 点一个概念打开右侧详情
  - 内容槽：概念名 / 依赖层级（L0–L5）/ 验收状态标识
- **默认不出现** —— 936 条概念不再常驻，这就是「三级可以隐藏」

### 主区 · 知识体系页内

- **视图 tab（图谱 / 星球）** —— **从全局顶栏拿下来**，回到知识体系这个页面内部（主区顶部）
- **画布** —— 图谱按主题分列；选中某条主题时只亮这一列（复用已有的 `filter` 机制）
- **右侧详情面板** —— 概念卡 + 倒逼输入框（本次不动）

### 主区 · 内参页

- 阅读页四个分页签（三级笔记 / 概念网络 / 费曼 ×3 / 阅读原文）—— **本次不动**

## 6. 目标衡量

**主指标（本次改完即可验证）：**
- 现场找 5 个没看过这个产品的人，**≥ 4 人**在无人讲解下 **60 秒内**完成
  「点知识体系 → 选一条主题 → 打开一个概念」三步

**漏斗指标（过程）：**
- 打开壳 → 落在哪个一级入口（内参 / 知识体系）
- 点「知识体系」→ 中间栏出 21 条主题
- 选一条主题 → 中间栏换成概念、画布只亮这一列
- 打开一个概念 → 右侧面板出现倒逼输入框
- 写下复述并交卷 → 拿到判定结果

**验证方式**：5 人现场观察 + 录屏（不做埋点——本次是黑客松 demo，样本量 5 人就够，人工观察比埋点快）。

## 7. 范围

**这一版会做：**
- 左栏一级导航顺序对调：**内参在上、知识体系在下**
- 主题从 L1（左栏）降到 L2（中间栏）
- 中间栏两级下钻：主题 ↔ 概念，带「← 全部主题」返回
- 图谱 / 星球 tab 从全局顶栏移到知识体系页内（主区顶部）
- 画布与主题筛选联动（选中主题时只亮该列）
- 搜索框留在一级（左栏），文案说清筛选范围

**这一版不做：**
- 不改画布渲染逻辑与倒逼判定
- 不动内参阅读页的四个分页签
- **不删星球**（保留，只是从顶栏降级为知识体系页内 tab）
- 不做移动端 / 窄屏专门适配
- 不动后端与 `/api/*`（`/api/health` `/api/llm` `/api/save` 等一行不改）
- 不做登录、账号、收藏、公开笔记
