## 4. 关键裁决（所有者 09-15 已拍板）

1. **DAG 投影成树**：os-taxonomy 原文明确数据是 DAG 不是树。处理＝主题×层级当骨架（树形投影），681 条依赖边不画全局线，只在概念卡上做「先懂这些 / 懂了它才能懂这些」局部双链；反向 unlocks 就是生长方向。
2. **只报绝对数，不报百分比**（09-12 路演红线：目录越长比例越误导）。
3. **不许自报变绿**（09-12 红线）：叶子只长在有证据的状态上。
4. **树是回看/浏览层，不是验收层**（验收靠复述；沿用 v2 裁决「知识体系＝浏览层」）。
5. 关系/星球**撤入口不删代码**（git 里留全尸，可回滚）；总图不删、挪「系统视图」小入口（所有者 09-15「我说的不是总图」）。

## 6. 用户与关键场景

### 场景 1｜评委第一次打开
顶栏点「知识树」→ 默认就是我的树：页头一句话 slogan＋「你的树 · N 片叶子有判定」；亮的叶子＝有判定记录的，点开即见「怎么算会了＋来源＋前置理由」。不需要讲解。

### 场景 2｜负责人回看自己长了多少
学完几章回来 → 树上多了几只带青环的叶子，页头数字变大——**只报绝对数**，没有「占了全树 x%」。

### 场景 3｜在树上看一个概念的来路
点叶子 → 概念卡「先懂这些」每条带 hard/soft＋理由（os-taxonomy 的边口径）；想看全局走「路径」，想看系统走「系统视图」。
