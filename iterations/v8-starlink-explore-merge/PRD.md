# 知所栖 135 · PRD · v8-starlink-explore-merge

> 本轮目标：把队友提供的「星链空间」接入现有「探索」页面，形成“介绍层 → 真实模块”的完整入口。
> 依据：`SOURCE_OF_TRUTH.md`、`docs/工作日志-知所栖135.md`、队友文件 `zhisuoqi-starlink-merged-v1.0.0.html` 的实际 UI 走查。

## 1. 问题定义

现有站点已经有内参、知识体系、实践空间，但探索入口缺少一段能让新用户先理解三者关系的产品叙事。队友前端已经提供首页提问入口和星链探索空间，但其中三个模块目前主要是介绍性内容，尚未接入本项目的真实页面与状态。

## 2. 本轮目标

将队友前端的首页与星链探索空间作为「探索」入口层，保留三模块顺序和介绍内容；用户看完介绍后，通过明确按钮进入本项目的真实模块。真实模块继续使用现有数据、路由、学习门控和服务边界。

## 3. 用户路径

```text
探索首页
  → 点击开始
星链探索空间
  → 选择 01 内参 / 02 知识体系 / 03 实践空间
模块介绍层
  → 阅读模块说明与方法步骤
  → 点击真实入口
现有真实模块
  → 可返回探索空间
```

不自动跳转。介绍层结束后由用户主动点击入口，保留用户对路径的控制。

## 4. 三模块映射

| 星链模块 | 介绍层职责 | 真实入口 |
|---|---|---|
| 01 内参 | 趋势观察、深度解读、判断留档；确定问题、保留依据、写下判断、定期回看 | 现有多期内参日报集合 `#neican` |
| 02 知识体系 | 概念地图、主题路径、连接与复习 | 现有知识体系 `#graph`，默认“我的树”，可进入路径 |
| 03 实践空间 | 项目实验、工具与方法、复盘与迭代 | 现有实践空间 `#practice`，主线六章与七站路线 |

介绍层中的示例文案不冒充真实数据，不新增第三套内容系统。

## 5. 页面与状态要求

### 5.1 探索首页

- 采用队友版首页的视觉语言：动态背景、品牌、提问框、`点击开始`。
- 左下角版本文案替换为本项目当前版本口径；不得保留“合并版 v1.0.0”作为产品名称。
- 首页问题输入是否参与真实查询，需按现有 API 能力接线；未接线前不得假装已经生成个性化路线。
- `点击开始` 只进入星链探索空间，不直接跳入某一真实模块。

### 5.2 星链探索空间

- 保留三个顶部模块：`01 内参`、`02 知识体系`、`03 实践空间`。
- 点击模块后打开对应介绍面板；星球仍可作为背景和返回锚点。
- 介绍面板可以有“下一步”进入模块方法说明，但最终必须提供明确的真实入口按钮。
- 三个真实入口按钮文案分别为：`开始阅读内参`、`进入知识体系`、`开始实践`。
- 介绍层和真实模块之间不能依赖第二套 iframe 长期保存业务状态。

### 5.3 真实模块与返回

- 进入真实模块后，保留轻量的 `← 返回探索空间` 入口。
- 返回时恢复星链探索空间，不丢失已选模块；页面刷新后按现有 hash 规则恢复。
- 现有内参筛选、知识树/路径、实践空间学习门控不改语义。
- 真实模块中的学习记录仍由现有状态系统负责，不由队友页面的 `localStorage` 概念导入机制替代。

## 6. 技术边界与部署

- 首期优先把队友前端作为探索层视觉与交互参考，移植到当前壳的视图结构；避免长期双 iframe 业务架构。
- 继续使用当前静态产物和本地服务：静态浏览不需要新增服务器。
- `/api/llm`、`/api/search` 仍由现有服务提供；不把密钥写入静态产物。
- 只有在需要向公网开放真实 LLM 或搜索能力时，才另行评估轻量服务器部署。本轮不购买服务器、不改变部署平台。

## 7. 验收标准

1. 首页视觉与队友稿一致到可识别程度，版本文案已替换。
2. 点击“点击开始”进入星链探索空间。
3. 三个模块均能打开介绍层，并能看到模块方法说明。
4. 每个模块都有明确真实入口，且不会自动跳转。
5. 真实入口分别落到 `#neican`、`#graph`、`#practice`。
6. 从真实模块可返回星链探索空间；浏览器后退、刷新和移动端入口不白屏。
7. 内参、知识体系、实践空间复用现有数据和状态；没有生成重复数据层。
8. 静态版不需要新增服务器即可打开；真实 API 仍走现有本地服务。
9. 跑完对应回归：`test-path`、`test-graph-view`、`test-mobile`、`check-public`、`test-app`，以及新增的探索/星链接线专项验收。

## 8. 本轮不做

- 不购买或配置新服务器。
- 不把队友的概念导入器作为我们的知识库写入口。
- 不重做概念地图、内参数据、六章材料或七站路线。
- 不让模型根据首页问题自动规划未经审核的路线。
- 不删除现有探索、内参、知识体系、实践空间能力。
- 不发布公网、不 push，除非另有明确授权。

## 9. 待执行时的实施顺序

1. 先建立队友版视觉资源与当前 `探索` 视图的对应关系。
2. 接通星链三个真实入口和返回状态。
3. 替换版本文案与按钮语义。
4. 做桌面、移动端、刷新、后退和静态版验收。
5. 通过验收后再讨论是否需要把星链节点接入真实概念地图。
