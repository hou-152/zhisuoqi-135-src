# 知所栖 135 · PRD · v9-tab-learning-clarity

> 本轮只处理 tab 边界、知识体系与实践空间的关系表达，以及新手进入路径。
> 长期项目口径见 `SOURCE_OF_TRUTH.md`；上一轮探索首页合并见 `iterations/v8-starlink-explore-merge/PRD.md`。

## 1. 本轮目标

让新用户能在不看内部术语的情况下，理解四个一级 tab 的职责，并分清：

- 知识体系的“路径”是概念理解顺序；
- 实践空间的“六章”是深度课程；
- 实践空间的“七站”是按问题组织的扩展地图；
- 六章与七站通过概念和单元交叉引用，共用学习记录，但不合并编号和步骤。

本轮不改变概念地图、六章材料、七站单元和学习门控的数据来源。

## 2. 一级与二级结构

### 一级 tab

| 一级 tab | 页面职责 |
|---|---|
| 探索 | 队友首页、星链空间、三模块入口与新手引导 |
| 内参 | 日报集合；进入文章后使用文章内 tab |
| 知识体系 | 纯浏览概念与关系 |
| 实践空间 | 课程入口、六章、七站和学习状态 |

### 知识体系内部 tab

只保留：`我的树｜路径`。

- 我的树：浏览 21 个主题和概念状态。
- 路径：查看当前概念的直接前置、完整理解路径和后继主题。
- 概念详情负责展示定义、怎么算会了、前置与来源。
- 知识体系不直接开始课程；进入实践空间必须通过明确的跨 tab 按钮。

### 内参文章内部 tab

继续使用现有文章内容 tab：三级笔记、概念网络、费曼、原文等。没有相应材料的 tab 不显示空状态。

### 实践空间内部结构

实践空间只有一个一级入口，内部按以下顺序呈现：

1. 继续学；
2. 主线六章；
3. 七站问题地图；
4. 概念全书和状态说明。

六章与七站不是 13 步连续课程，也不是两个一级 tab。

## 3. 六章与七站的关系

六章负责纵向深度：

`Agent → 工具 → Agent loop → 状态子系统与进度持久化 → Harness → 验证闭环`

七站负责横向问题入口：

1. 眼前真正有什么；
2. 信息平时放在哪里；
3. AI 如何持续行动；
4. AI 如何接触外部世界；
5. 人如何控制 AI；
6. 信息如何进入工作台；
7. 做完后凭什么相信。

页面必须展示六个明确锚点：

| 六章 | 七站锚点 |
|---|---|
| Agent | 第 3 站 |
| 工具 | 第 4 站 |
| Agent loop | 第 3 站 |
| 状态 | 第 2 站 |
| Harness | 第 3 站 |
| 验证闭环 | 第 7 站 |

七站第 1、5、6 站没有独立六章锚点，页面照实说明其为扩展问题入口。

## 4. 学习闭环口径

六章的产品闭环固定为：

`正文阅读 → 三道决策 → 复述验收`

“5 实验”已经从产品中丢弃，不属于实践空间、内参文章或 135 闭环。页面不再出现“5 实验”作为产品步骤，也不再保留接入实验的待决项。

## 5. 筛选与状态边界

- 每个一级 tab 使用独立筛选状态。
- 探索不复用知识体系的主题筛选。
- 内参分类按当前日期或期数显示有效计数；空分类不展示。
- 切换 tab 后，不能因为残留 `agent` 等搜索词把知识体系压缩成一个主题。
- 从知识体系进入实践空间时，带上来源概念和返回位置，但不把两个页面变成同一 tab。

## 6. 新手路径

新用户默认路径：

`探索 → 了解三个模块 → 选择一个入口 → 内参 / 知识体系 / 实践空间`

首次引导最多三步，每一步只说明一个模块和一个动作。探索页面不得声称已经根据问题生成个性化路线，除非真实能力已接通。

## 7. 范围

### 本轮做

- 固定四个一级 tab 和各自内部层级。
- 在实践空间补充六章—七站关系图和交叉引用。
- 修复筛选状态串 tab 的问题。
- 统一学习闭环文案，消除“135 已完整实现”的误导。
- 清理学习者可见的内部术语和无效小字。
- 为探索、知识体系、实践空间分别定义新手入口和返回行为。

### 本轮不做

- 不重建概念地图和七站排序。
- 不把知识体系路径改成课程解锁路径。
- 不把六章和七站合成一条 13 步路线。
- 不新增未经审核的自动路线。
- 不在本轮发布公网或 push。

## 8. 验收

1. 四个一级 tab 的名称和职责在桌面、移动端、桌面版一致。
2. 知识体系只出现“我的树｜路径”；实践空间不被拆成新的一级 tab。
3. 七站页面能看到六个六章锚点及其对应关系。
4. 从任一概念进入实践空间后，返回能恢复来源位置。
5. 在一个 tab 输入搜索词，切换其他 tab 不会改变其内容集合。
6. 新用户能说出“六章是深度课程，七站是问题地图”。
7. 页面统一使用“阅读 → 决策 → 复述验收”，不出现“5 实验”产品步骤。
8. 现有 `test-path`、`test-graph-view`、`test-mobile`、`test-app`、`check-public` 全部回归通过。

## 9. 风险与待决事项

- 七站与六章的交叉引用先采用人工锚点，不自动依据图谱边排课。
- 队友星链视觉只作为探索层入口，不覆盖知识体系和实践空间的状态逻辑。
