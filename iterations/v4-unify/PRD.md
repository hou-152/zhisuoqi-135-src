# 知所栖 135 · PRD · v4-unify

> 文件位置：`iterations/v4-unify/PRD.md`。写于 2026-09-15（交卷日凌晨）。
> 范围与所有者 09-15 凌晨对话裁决一致：**全做**；内嵌三步＝内参 / 知识体系 / 实践空间；
> 「知识树」更名回「**知识体系**」以统一队友前端；队友模块等源码到位后合并。

## 1. 背景

队友前端（chatgpt.site 部署稿，源码未到位——站点对本机 Cloudflare 403、GitHub 无公开仓库）定了三个模块名：**内参 / 知识体系 / 实践空间**；另有「探索」入口进 AI 内嵌首页。所有者裁决：模块名统一用队友口径，v3 的「知识树」更名回「知识体系」（slogan「将知识转化为属于你的知识树」保留为标语，我的树视图不变）。本轮同时收口 UX 四件（内参日期滚动、已选行换行、系统视图回不去、镜头瞬移）与路径取景。

## 2. 范围

**做：**
1. **命名统一**：一级导航「知识树」→「知识体系」（含「← 返回知识体系」），顶栏加第一模块「**探索**」（AI 内嵌首页）；v3 相应断言回改
2. **内参日期**：默认选中最新一期（单期视图）；期头「‹ ›」翻期；「全部」降级为按钮（保留堆叠+scroll-snap）；已选行改短格式「已选 9月14日 周一 · 8 篇」＋`.cf` 上下两行不换行；全产品日期格式统一（窄列短格式 / 页头全格式）
3. **更新面板**：顶栏灰字「更新」→ 下拉面板（v4/v3/v2/v1/交卷版，日期+一句话），数据 build-shell 从 iterations/*/PRD.md 烘焙；面板底部「系统审计视图 →」（`#graph=map`，标注 repo 路径 scripts/lib/graph-view.js · knowledge/graph-260914/）
4. **系统视图撤 tab**（B-lite）：「系统视图」从 tab 板撤掉（tab 板=我的树｜路径），hash 直达与 graph.json/runner（学习空间门控依赖）全部保留
5. **镜头缓动**：画布镜头 ease-out ~420ms 补间；套用点主题下钻/树⇄路径/全览/进视图；滚轮、拖拽即断
6. **路径当前步视角**：进路径默认以当前步为中心的可读取景；「看整条」按钮保留整条视角
7. **探索 / AI 内嵌首页**：顶栏第一模块 → AI 内嵌首页；首次进入给 ChatGPT 式三步引导（每步配图+小字：内参 / 知识体系 / 实践空间；进度点+下一步+跳过，完成态记 localStorage）；完成后为 AI 内嵌面板占位（照实标「前端由队友模块提供，合并中」）

**不做（本轮）：** 队友前端合并（等源码，phase 07 占位）；内嵌的 AI 对话后端（合并后接）；系统视图内容改动；百分比统计；移动端。

## 3. 关键裁决（所有者 09-15）

- 模块名以队友前端为准：内参 / **知识体系** / 实践空间；探索置顶第一
- 内嵌引导三步＝介绍三个模块（配图+小字）
- 系统视图「可能已经没有价值」→ 撤出主界面，数据层保留（学习门控依赖）
- 全做；「做这个并不难，就等他的前端，最后合并」
