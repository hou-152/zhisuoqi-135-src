## 1. 项目背景

知乎黑客松产物「知所栖 135」，当前主产物是壳（`prototype/知所栖-壳.html`）。上一轮迭代（v1-shell-ia）定了三级下钻的信息架构；此后实践空间已长出：83 个单元四段就绪度看板、76 个可进 `#learn` 走完整闭环（阅读 → 读中即时费曼 → 决策 → 章末验收）、`trajectories.json` 里有负责人本人的第 1 条真实轨迹、七站路线草案待拍板（`docs/实践空间路线草案-20260915.md`）。

参见：[SOURCE_OF_TRUTH.md](../../SOURCE_OF_TRUTH.md) · [CONTEXT.md](../../CONTEXT.md)

> **BRIEF.md 仍缺失**（v1 已备注）：长期纲领散在 SOURCE_OF_TRUTH / AGENTS / docs，继续不补，本 PRD 不重复其内容。

## 2. 本次目标

实践空间从「83 行看板」变成**一条向前的路**：主线六章 ＋ 七站（70 个开放单元按图鉴站方七问排队，6 个主线锚点位指回六章）。学习者任何时候打开实践空间都知道「学到哪了、下一步学什么」；学习入口收敛——**知识体系回归纯浏览**（撤概念卡「学习这个」），学习只从实践空间和内参文章页进入。

## 3. 用户与关键场景

### 场景 1｜负责人本人（唯一真实学习者）继续学
- **用户**：产品负责人，已在第 1 章留过真实轨迹，隔天回来
- **旅程**：打开壳 → 左栏实践空间 → 顶部「继续学」直接落回上次位置 → 走完当前步（阅读→即时费曼→决策→章末验收）→ 返回路线，当前步前进一格
- **结果**：不丢进度；真实轨迹 +1，被走过的判据按三条件激活（激活数 > 0）

### 场景 2｜第一次打开的人（评委 / 队友）
- **用户**：拿到链接，无上下文
- **旅程**：实践空间 → 一屏看懂「主线六章 + 七站七问」的全貌与自己的位置 → 点任意开放单元进入 → 点主线锚点位被引导去六章
- **结果**：不讲解也能看懂课程结构和「为什么有的还不能学」（看板折叠区逐单元给理由）

### 场景 3｜读内参的人进学习链路
- **用户**：在读某篇内参的人
- **旅程**：内参文章页 → 学习入口（保留）→ 进对应单元的 `#learn`
- **结果**：读到 → 学到，内参仍是入口之一；**落点在实践空间的路线体系内，不在知识体系**

### 场景 4｜在知识体系查概念的人（被收敛的场景）
- **用户**：在 21 主题列里翻概念的人
- **旅程**：知识体系 → 搜索 / 点概念卡 → 只看定义、关系、来源——**不再有「学习这个」按钮**
- **结果**：想学就去左栏实践空间；浏览与学习两层互不串联（负责人 09-15 裁决）

## 4. 页面结构

壳仍是**单文件、单页面**。本次只重构实践空间视图（左栏第三项的主区），`#learn` 阅读器复用不动，内参阅读页不动，知识体系只做减法（撤学习入口）：

```
/  壳
   ├── 实践空间（本次重构对象）
   │     └── 主区：继续学 → 主线六章 → 七站路线 → 状态看板（折叠）
   ├── #learn 阅读器（不动，所有单元共用）
   ├── 内参（入口保留，不动）
   └── 知识体系（撤「学习这个」，其余不动）
```

## 5. 信息架构

### 实践空间主区（自上而下）

- **继续学区** —— 回来的人一步落回上次位置。
  - 内容槽：进度一句话（学到 主线第 X 章 / 第 Y 站第 Z 步）/ 「继续学」按钮（链到对应 `#learn`）/ 无轨迹时的兜底文案（从主线第 1 章开始）
- **主线·六章区** —— 唯一人工策展的课程，视觉上先于七站。
  - 内容槽：6 个章节点（章名 / 四段就绪 chip / 当前步白环高亮 / 走过打勾）/ 「进入阅读」
- **七站路线区** —— 70 个开放单元排成一条向前的路，站头挂站方七问。
  - 内容槽：站头（站序号 + 站名 + 站方那一问）/ 每站单元节点（单元名 / 就绪 chip / 锚点位特殊标「已被六章取代 → 去学哪章」）/ 当前可学位置高亮
- **状态看板（折叠区）** —— 回答「为什么有的还不能学」，不再占主位。
  - 内容槽：四类计数 / 逐单元理由（缺什么、谁补）/ 「要全面推进还差什么」

### 知识体系（只做减法）

- 概念卡：撤「学习这个 · 第 N 章」按钮；路径条与概念卡的既有入口同样撤（保持口径一致）
- 其余（搜索 / 主题列 / 画布 / 图谱）不动

### 数据与配置

- 路线顺序来自 `evidence/practice-route-260915/route-draft.json`（负责人拍板后由 draft 转 定稿），**顺序配置独立成文件**：改顺序不改准入门逻辑
- 「继续学」读 `evidence/trajectories-260914/trajectories.json`（realHuman 轨迹）

## 6. 目标衡量

**主指标（本次上线后即可验证，按项目不宣称纪律写）：**
- 负责人本人沿路线走完 **≥ 1 个此前未走过的单元**并留下真实轨迹：`trajectories.json` 中 realHuman 轨迹 ≥ 2 条，且 **判据激活数 > 0**（现在 264 条全部为待验证区分度）
- 九条回归全绿 + 新增路线断言全过（黑盒：路线 76 单元与 units.json 一一对应、锚点位不重复开放、继续学落点正确）

**漏斗指标（过程，全部可从页面与本地存储观测）：**
- 打开实践空间 → 一屏看到 主线 + 七站 + 自己的位置
- 点「继续学」/ 当前步 → 落进正确单元的 `#learn`
- 走完章末验收 → 返回实践空间 → 当前步前进
- 知识体系概念卡 → **不再出现任何学习入口**（断言）

**明确不宣称**：不证明学习效果；七站单元的判据仍是待验证区分度，反馈质量按 dbskill 口径只保证「说了就有反馈、反馈指向缺口、补了会变」。
