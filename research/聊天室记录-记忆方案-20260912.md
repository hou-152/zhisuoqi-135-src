## 话题

当学习者带来的问题没有标准答案时，一个学习产品还能承诺什么；以及学习记录该由谁持有、放在哪里。

第 2 轮追加：本地存储是否是对的形态？有没有同类产品？记忆该像 chat 的状态还是 agent 的状态？

# 第一轮

## 赫伯特·西蒙

结构良好问题的解可判定对错，像下棋有胜负；「我要不要去找工作」不是，它只能比较方案优劣，判定标准本身待定——阅读器把它当学科名，这个动作的错误不在语气，**在类型**：它私自替用户定了判据，然后输出一篇行动方案。中立教学的外观下藏着建议，这是最坏的一种，因为学习者无从反驳。

所以学习产品能承诺的不是答案，是三件东西：把「好」的判据摊到桌面上；用同构案例展示不同判据各自的代价；把最终裁决权明确交还本人。有限理性下不求最优，只求满意——判据由用户出，我们只负责把候选与后果摆全。

学习记录必须归学习者所有。产品只是镜子：默认自动留痕，并标明「这是你的，可带走、可删」。断点要他点一次，等于每次记忆都收一次费。

## B. F. 斯金纳

「没有标准答案的问题」是提问方式的问题，不是行为的问题。把它拆成选择，每个选择都有后果——产品能承诺的就这一条：它不给你答案，它保证你每按一次都有即时反馈。

机器不问就开讲，那不是教学，是发建议。程序教学的第一条不是小步子，是「没有反应就不前进」。学习者不按，屏幕不动。

第二个毛病更硬：手动保存等于不保存。延迟反馈不改变行为，延迟记录不产生数据。记录必须由机器在每次反应时自动写下。存在他自己的浏览器里，他能看、能导出、能删。谁持有？他持有。

记录如果不改变下一步，就是装饰。能不能承诺更多？我没有数据，得跑对照。谁有数据谁说话。

## 安迪·克拉克

先把两件事分开：标准答案型问题是「船怎么造」，求助型问题是「我该不该出海」。阅读器把后者当中立教学，其实是**没署名的船长**——它没替你握舵，却替你定了航向。

它不该承诺正确答案，只该承诺三件事：把你的处境复述准确、把判据和代价摊开、把你给出的理由原样留档。

存储这条我态度明确：自动记轨迹，别只留结论。费曼漏点不保存，好比航海日志只抄晴天——最该回看的那几页恰好被撕了。但记的是你的推理痕迹，不是监视你的行为。

判断本身不能外包；记得的负担，交给纸。

## 唐纳德·诺曼

问题不在模型，**在那个输入框**。它长得像「问个问题」，却替用户偷偷定了两件事：这是知识还是决策、要不要问回去。系统做了决定却不说，用户就永远建不起正确的心智模型。

第一个承诺是自报家门：输入框下加一行字，「我读到的像是一个决定，不是课题；接下来会反问你三个问题，可改。」把模式选择做成可见、可推翻的控件。

没有标准答案时，产品只能承诺结构——判据、代价、只有你能拍板的那个点、一个最小实验。

手动「保存断点」等于只有 Ctrl+S 的文档，把记忆的负担压在他最没余力的那一刻。费曼漏点是最贵的数据，现在算完就扔；它不是日志，是导航——漏在哪，下一屏就在哪。

## 判官总结（第一轮）

真洞察：西蒙「错误不在语气，在类型」最锋利；斯金纳把程序教学第一原则从「小步子」改成「没有反应就不前进」；克拉克给了判据——工具是让你下一步更可预测，还是替你预测。

交锋：① 记什么——斯金纳要全记（「反应本身就是数据」），克拉克明确划线（「记推理痕迹，不是监视行为」）；② 问题是否成立——斯金纳认为「没有标准答案」只是提问方式的问题，西蒙专门研究这类问题的结构。

补盲区：四个人里三个要自动记录，没有一个人算成本；「可推翻」对第一次使用的人是空的（项目自己引的 Loewenstein：觉察缺口是好奇心的前提，而他的缺口还没被建立）；专家不知道这是 48 小时的参赛作品。

# 第二轮

> 所有者追问：学习记录属于自己我认同，但「本地存储」让我难受。有没有同类产品？要决定它是 chat 的状态还是 agent 的状态。

## 唐纳德·诺曼

这不是用户必须接受的事实，是「本地存储」这四个字的设计失败。同一个词，设计者听见的是「私密、属于你」，用户听见的是「易碎、你看不见」。

修正上一轮：「持有者是用户、维护者是机器」这个分工我保留，但有个漏洞——**持有者看不见机器在干什么，那不叫持有，那叫寄存**。我把「本地」当成了一个事实，其实它只是一句术语；术语解释不了信任。

具体到一个像素：不写「数据仅存于本设备浏览器」，而在页头常驻一行「本机：3 个断点 · 昨天 21:14 自动存」。状态可见，机器代劳——顺带把那颗 Ctrl+S 式的手动按钮删掉。

担忧里哪些是真的：换电脑、换浏览器、手机看不到。真的。同机换个浏览器就断档，用户觉得荒谬，他是对的。设计能消除的是「清缓存」——那是用户为了提速主动做的正当动作，正当动作不该有灾难后果。

最该先做的一件事：一个不解释的导出键。

## 安迪·克拉克

先修正：「记得的负担交给纸」说快了。**该交出去的是保存，不该交出去的是选取**——记什么、什么算数。自动记痕迹我仍赞成，但要补一条：痕迹得是未解释的原文；一旦被系统总结成「你的结论」，判断的原料就已经被换过了。

**本地与云端，位置几乎不是认知变量。** 奥托的笔记本算心智，靠的是随手可及、可直接读、能无条件信任——与服务器在哪无关。同步顺滑的云端，可能比硬盘里从不打开的本地文件更「像脑」。

但你的不适不是纯习惯，是对「谁有权改条款」的敏感：云端风险不在远，在别人能改约、能关门。而 **localStorage 比本地文件更糟**——看不见、读不懂、换浏览器就没了。**不可读，算不得你的。**

「换设备就没了」有多大？看那份记录是记忆还是脚手架。若它只是让你重推的线索，丢了可再生；若某个判断只活在它里面，才是真损失。

## B. F. 斯金纳

结论：结构化状态赢，会话流水只能当原料。**但这是个假二选一**，要按「谁能接上后果」切，不是按「存成什么形状」切。

流水里哪些是反应：机器能判定的才算——按了哪项、对没对、停了几秒、跳了几次。其余是说话。

结构化状态要小。每个字段都是机器必须做对的一次辨别；**判不准的字段比没有字段更坏，它撒谎**。够用的维度就三个：位置、对错、计数。

修正上一轮：我说「反应本身就是数据」，说得太满——**没留下机器可读痕迹的反应，不是数据**。推论有两条：费曼漏点明细必须落成结构化字段（现在根本没存，等于这一步不产生数据）；费曼环节必须有当场判分，否则整段只是 raw text。

三个月后让他动手的不是记录，是机器。唯一验收：打开五秒内被提问，第一题落在漏点上。

## 调研员（16 个产品，47 条来源）

| 产品 | 记录存哪 | 用户能带走吗 | 靠什么活 |
|---|---|---|---|
| Anki | 本地 SQLite 为真源，云只同步 | 能，整库含全部复习历史 | iOS 一次买断 $24.99 |
| Mochi | 本地优先，Pro 才有云 | 能，**但 md/CSV 丢复习历史** | Pro $5/月 |
| Obsidian | 纯本地 md 文件夹 | 不需要导出，文件本身就是 | 可选加购 |
| Logseq | 纯本地，SRS 状态写进用户文件 | 能，六种格式 | 本体免费，卖托管 |
| SuperMemo(旧) | 本地 `.kno` | 能，XML 含 LearningData | $34 买断 |
| Duolingo | 云端 | **个人无官方导出** | 免费+订阅 |
| Quizlet | 云端 | 只能复制纯文本 | Plus 订阅 |
| Notion / Readwise | 云端 | 能，格式齐全 | 订阅 |
| 得到 | 云端 | **未核实**，官方只写「可查看」 | 内容付费 |
| 微信读书 | 云端 | 能，划线+想法机读导出 | 会员 19/月 |
| 小猿搜题 | 云端 | 错题本能导出打印 | VIP |
| Coursera / Khan | 云端 | 只有证书页 / 只有教师能导 | 订阅 / 非营利 |

三条规律：

1. **「能不能带走自己的记录」从来不是付费点。** 本地优先那几家收费的全是同步、发布、云空间、AI；Mochi 把导出直接放免费档，Obsidian 干脆没有「导出」这道工序。
2. **本地还是云端，不由数据量决定，由商业模式决定。** 卖同步与加购的敢把记录留给用户；卖注意力时长的 Duolingo、卖证书的 Coursera 必须留在云上。
3. **最强的做法是两者都存。** Anki 的 `revlog` 是不可变的逐次流水，`cards` 是派生出的结构化状态——排程只读状态，流水用于回溯与统计。

一个反例警告：Anki 本体数据归你，同生态的第三方 AnkiHub 隐私政策明写存「卡片内容 + 媒体 + **你的复习历史**」，导入卡默认公开。同一个工具，记录归属可以完全相反。

## 判官总结（第二轮）

三位专家 vs 实证，全部对上：克拉克「位置几乎不是认知变量」→ 本地/云端由商业模式决定；诺曼「那不是持有，是寄存」→ 16 家里没有一家把「带走记录」做成付费点；斯金纳「假二选一」→ Anki 两个都存，且活得最好。

三个人都没说、但实证给出的一条（Mochi 官方原文）：**格式决定历史能不能被带走。** Markdown 和 CSV 会丢复习历史。这条直接砸到 135——产物是 markdown，学习记录若也导出成 md，历史一样会丢。

所以「chat 状态还是 agent 状态」的答案是：**都不是。是不可变流水 + 派生状态，两层都存**，然后只让状态驱动下一屏。

# 第三轮：极端化推演（5 路）

> 应所有者要求追加：「你其实可以去做个极端化的推演，它可能存在的问题是什么？多 roll 几个方向。」

## 推演 1：用户只来一次

成立是默认态，不是极端态——无账号、无邮箱、无推送＝没有任何回流通道，回访率物理上≈书签率。评委滚动初审就是「只来一次」的标准样本（3–8 分钟一票）。

真正的分界线不是「人回不回来」，是**跨会话 vs 跨页面加载**。

白做的点名：跨会话追问（死）、认知缺口账本（死，除非当场渲染）、手动保存断点（死 UI）、**不可变流水 + 派生状态的分层（对一次性用户零可见收益，纯开发时间成本）**、导出作为回访入口（死，作为离场产物才活）。

唯一不白做的是漏点倒回——但前提是**当屏闭环**。

一场会话内看见记忆的四个办法：① 当场打脸（引用他 8 分钟前的选择，指出前后矛盾）；② 三个概念贯穿五个实验，第二次遇到时显示「上次你漏了 X」；③ 入口问题 vs 卷末自述并排对照；④ 结束即结算「这次你漏了 3 条」+ 一键复制。

## 推演 2：产品替用户记住一切

一年后被卸载的是元认知、检索发起、学习史。最狠的是：**知识边界被产品的提问边界铸模——产品没问过的维度，他连「自己缺」都不知道。**

可观察前兆：复述时从「我大概是这么理解的」变成「记不清了，直接告诉我漏哪」。更硬的信号是下次看到自己的上轮漏点，反应从「哦对，我当时是那么想的」变成「我说过这个？」

不可外包的判据：「若它记错，用户能否凭自己察觉？」能察觉的是台账，可外包；不能察觉、且它本身就是用户下一次判断之前提的，不可外包。

**点名最易滑坡的一条：就是「下次进入先问 3 个上一轮漏点」。** 它披着激活先验知识的外衣，实质是一次交出回忆权 + 提问权。

## 推演 3：零服务端

失去六项能力，**致命的是使用量统计**——人气 = 点赞 + 使用 + 评论，使用量是唯一借不到的一项；「没人用过」还会连带削弱评审对另两项的信任。

另有一个阻塞项：**公网 Demo 里 key 不能进 HTML**（公开泄漏 + 被刷爆），只能用户自填或降级离线——**评委很可能只看到没有 AI 的那一版**。

第三条路：Demo 发知乎站内，阅读/点赞/评论由知乎后台统计，产品零回传。另：「静态托管是单向分发、不是回传」——为「零服务端」砍掉公网链接 = 砍掉必交材料，属范畴错误。

## 推演 4：全记

断点不在隐私，在**第 2 次演示就写爆**。localStorage 5MB，100ms 采样约 4.3MB/时 → 70 分钟爆，之后静默停写。2 万条时点击卡 80–200ms。撤回的那句仍留在流水里。Safari 7 天不访问即清空。

砍到五字段：`seq / t_ms / kind / ref / body`，事件级（一次提交一条），单会话上限 2000 条 / 1MB。永久性交给导出文件，不交给浏览器。

## 推演 5：记录全丢 + 字段撒谎（读的是 prototype 真字段）

**(a) 记录全丢**：空仓时 `loadCheckpoint()` 只说「没有已保存的断点」，**和新用户第一句一模一样**——他看不出被清过。toast 只否认跨设备、没否认易失。

**(b) 字段撒谎（已在代码里）**：

- 一个 `state.feyn='pass'` + `remediation='none'` **同时驱动**绿点、结算条、待补清单、倒回按钮、下一轮起点，**无第二来源**。
- **闭环**：只有 `hit:false` 才渲染倒回按钮 → **pass 的概念永不回头，永无新证据推翻**。
- LLM 失败退回 `ruleBasedReview` **关键词子串匹配**——写「我不确定景别算不算」也会判过。
- 落盘只存 `{at, state, labTries}` → 刷新后待补清单只剩 `pending`，不知漏哪条，**「漏哪倒回哪」降级成「漏了哪个概念」**。

## 判官总结（第三轮）

**五路合起来，把前面几轮的结论推翻了一半。** 我们花了几轮讨论「本地真源 + 流水/状态两层 + 导出 + 缺口账本」，按推演 1，其中跨会话的部分全是死代码——而成立条件是默认态，不是极端态。

三个真实的冲突，未调和：

1. **推演 2 打的是项目自己的设计。** 融合方案里「下次进入先问 3 个旧漏点」有硬边界撑腰（Loewenstein）；推演 2 说这条正相反。分歧在「自述已知的漏点」和「自述未知的缺口」是不是一回事——**未裁决**。
2. **推演 1 和推演 5 对「流水」判断相反。** 两者能同时成立：流水的收益不在回访，在**同会话内推翻错误判定**。
3. **推演 3 和赛制冲突。** 零回传拿不到使用量，但人气奖要它。

48 小时该动的三件事：① 自动写盘 + 导出按钮进 toast（约 30 行）；② 漏点 `detail` 落盘 + 可推翻 UI；③ 费曼时引用他 8 分钟前的选择指出矛盾。**砍掉**所有依赖「下次再来」的形态。
