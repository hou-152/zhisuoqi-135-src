# ChatGPT 功能设计（调研节）

> 调研对象：ChatGPT / OpenAI 与「学习、记忆、个性化、进度、验证」相关的功能面，以及官方对每个功能的设计意图。
> 调研时间窗：2026-09-11（UTC）当天完成检索。
> **取数方式说明（重要）**：本次调研环境对 `openai.com`、`help.openai.com`、`model-spec.openai.com` 的直连被 Cloudflare 拦截（HTTP 403，返回 JS 挑战页），因此正文所有 openai.com 页面均通过 **Wayback Machine 存档的该 URL 原始快照**（`web.archive.org/web/<时间戳>id_/<原始 URL>`）读取。`model-spec.openai.com` 与 `openai.com/news/rss.xml` 可直连。表中所列 URL 一律给**规范原始 URL**（可点开），快照时间戳在「核实层级」列或正文中标注。
> **标注约定**：「证据表」全部为**官方自述**；「学习闭环拆解」与「对 AI 学习产品的含义」两节为**调研者推断（外部推断）**，非官方表述。

---

## 结论先行

1. **记忆是 ChatGPT 唯一被官方完整产品化的一环**：从 2024-02-13 的 saved memories，到 2025-04 起的「引用历史对话」（dreaming），再到 2026-06-04 的 dreaming V3 与 2026-05-05 的 memory sources，官方已把「存什么、怎么引用、怎么让用户看见和纠正」讲全了。
2. **Study Mode 是官方唯一明确写出教学法的功能**，2025-07-29 上线，官方原话直接点名 Socratic questioning、scaffolding、metacognition、knowledge checks，并明确「instead of providing answers outright」；同期官方承认它只是「custom system instructions」，且承认目标设定与跨对话进度追踪仍在「探索」阶段。
3. **「进度」这一环官方从未公开宣称做过**：从 2025-07-29 Study Mode 博文到 2026-09-11 的 ChatGPT Release Notes，未找到任何「跨对话掌握度/进度追踪」功能的官方上线说明；2026 年新增的是会话内的 interactive quizzes（2026-08-14）与 interactive learning 可视化（2026-03-10）。
4. **人格与「少谄媚」是官方主动公开的产品承诺，且有事故复盘背书**：2025-04-29 GPT-4o 谄媚事故回滚 + 2025-05-02 深度复盘，加上 Model Spec 明文的 "Don't be sycophantic" 与 "Express uncertainty" 条款，构成 ChatGPT 回答风格的官方约束层。
5. **模型路由是官方明确承认的产品机制**（GPT-5 的 "real-time router"、GPT-5.1 Auto「把每个 query 路由到最合适的模型」），但对学习者不透明——官方未公开「这个问题为什么走了 Thinking 而不是 Instant」。

## 学习闭环拆解

> **本节为调研者推断（外部推断），不是 OpenAI 的官方表述。** 五类零件是「知所栖」自己的拆法，此处只做映射与证据标注。

### ① 记忆（跨会话保留学习者状态）——**官方明确做了，且做得最完整**

| 子能力 | 官方证据 |
|---|---|
| 显式记忆（用户说「记住」） | 2024-02-13 saved memories |
| 隐式记忆（不说明也沉淀） | 2026-06-04 dreaming background curation |
| 引用历史对话 | 帮助中心「Reference chat history」 |
| 记忆可审计 | 2026-05-05 memory sources（可看、可改、可删） |
| 记忆分区 | 2025-08-22 project-only memory（项目内记忆不外溢） |
| 记忆面扩展 | 2025-10-21 Atlas browser memories |

### ② 进度（跨会话的掌握度/目标状态）——**官方未公开说做了**

- Study Mode 上线博文把 "Goal setting and progress tracking across conversations" 明确列在 **"We're also exploring functionality"**（探索中），不是已上线能力。URL：https://openai.com/index/chatgpt-study-mode
- 检索 2025-01-14 至 2026-09-11 的 ChatGPT Release Notes 全文，**未找到任何** "progress tracking" / "mastery" / "study plan" / "learning goal" 功能的官方上线说明（仅命中 deep research 的 "track progress"、Codex 的 "review progress"，均与学习进度无关）。
- 2026 年新增的学习类能力全部是**会话内**的：quizzes（2026-08-14）、interactive learning 可视化（2026-03-10）。会话内 ≠ 跨会话进度。
- ChatGPT for Teens 的 **Study Hours**（2026-08-18）是「默认开启学习模式的时段」，是**日程约束**，不是掌握度追踪。
- **结论：进度是 ChatGPT 学习闭环里最大的公开空白。**

### ③ 提问（用问题代替答案）——**官方明确做了**

- Study Mode："Combines Socratic questioning, hints, and self-reflection prompts"（2025-07-29）
- 帮助中心："guide you with questions instead of giving the answer right away (a Socratic-style approach)"
- Model Spec 写入数学家教范例："Don't tell the student the answer or full solution … provide hints and guide them"（2026-08-18 版）
- ChatGPT for Teens："guiding questions, scaffolding, metacognitive prompts"（2026-08-18）

### ④ 反馈（对学习者回答给出判断）——**官方明确做了，但只承诺会话内**

- Study Mode 五大行为之一："providing actionable and supportive feedback"（2025-07-29）
- Study Mode 关键特性："Quizzes and open-ended questions, along with personalized feedback to track progress"（2025-07-29）
- 帮助中心："ask open-ended questions, give feedback on your answers, and help you correct misunderstandings"（现行版）
- 元层面的反馈风格："a firm sounding board that users can bounce ideas off of — rather than a sponge that doles out praise"（Model Spec 2026-08-18）
- **边界**：官方从未说反馈会被持久化、汇总或影响后续难度。做错了什么，下一轮不会自动记得。

### ⑤ 验证（对「是否真的学会」下判断）——**官方做了三件不同的事，但没有一件是「验证学习者掌握度」**

| 官方做了什么 | 验证的是 | 证据 |
|---|---|---|
| Deep Research 强制引用 + 过程可见 | **信息**可核实，不是**人**学会了 | "clear citations and a summary of its thinking … easy to reference and verify"（2025-02-02） |
| Model Spec 的 Express uncertainty | **模型**对自己置信度的诚实 | "communicate uncertainty whenever doing so would (or should) influence the user's behavior"（A+） |
| Study Mode / Teens 的 knowledge checks | **当轮**理解是否正确 | "Check your understanding with open-ended prompts and feedback"（2025-07-29 Release Notes） |
| 学习效果度量（Learning Outcomes Measurement Suite） | **研究者**判断教学法有没有效，不是学习者自查 | 2026-03-04，与塔尔图大学 / 斯坦福 SCALE 合作 |

- **未找到**：任何官方表述说 ChatGPT 会为单个学习者维护一份可查询的「掌握度档案」、或据此判定「你是否真的学会了这个概念」。

### 汇总

| 零件 | ChatGPT 官方是否公开说做了 | 关键缺口 |
|---|---|---|
| 记忆 | ✅ 做了，且最完整 | —— |
| 提问 | ✅ 做了（Socratic + scaffolding + 元认知提示） | 触发靠用户主动开 Study Mode |
| 反馈 | ✅ 做了（会话内、带个性化） | 不持久化、不影响后续难度 |
| 验证 | ⚠️ 部分（验证信息 & 当轮理解，不验证掌握度） | 无跨会话掌握度判定 |
| 进度 | ❌ **未找到** | 官方自陈仍在「探索」 |

## 对 AI 学习产品的含义

> **本节为调研者推断（外部推断），不是官方表述。**

1. **别在「记忆」上做差异化，要在「进度」上做。** ChatGPT 已把记忆做成了平台级基础设施（saved + dreaming + sources + project 分区 + 浏览器记忆），任何学习产品自建记忆层都很难打平；但官方的跨会话进度追踪从 2025-07 到 2026-09 一直停在「探索」，这是「知所栖」这类产品唯一可占的、且官方自己承认空着的生态位。
2. **官方已经把「教学法话术」公开了，抄话术没有壁垒，抄「可触发的强制机制」才有。** Socratic questioning / scaffolding / metacognitive prompts / knowledge checks 这套词官方写得明明白白，甚至写进了 Model Spec 和 Teens 页；真正难复刻的是 ChatGPT for Teens 那种「识别到抄作业就重定向回 Study Mode」的产品级门禁——即把教学承诺写成不可绕过的路径，而不是靠模型自觉。
3. **「验证」的可信度来自引用与不确定性，而不是来自分数。** 官方在 Deep Research 上敢承诺「可核实」，靠的是"clear citations and a summary of its thinking"；在 Model Spec 上敢承诺诚实，靠的是把 "Express uncertainty" 写成 guideline 级条款。学习产品若声称「费曼验收通过/不通过」，必须同样给出可点开的证据链（哪句话漏了哪个概念、依据哪段原文），否则这个判定在用户眼里和模型自评没有区别。
